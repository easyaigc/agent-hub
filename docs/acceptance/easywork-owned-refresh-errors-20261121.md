# EasyWork 授权暂态错误和原刷新恢复

当前结果只维护于 [唯一台账](../plans/ios-easywork-alignment-20261112/status.json) 的 `F07-authorization-error-recovery-matrix`。本页定义范围，不维护完成数。

使用本任务独占的新 iOS 模拟器及新设备授权，不复制原模拟器钥匙串、连接、草稿或旧 grant。正常配对只确认准确设备、完整目标和公钥。旧五项绑定及原数据分别核对保护。

独立 actor 的窄 HTTP 依赖只对本任务固定 issuer、POST、operationId、正文及 token 摘要命中的请求返回受控 408/429/503。它们用于真实原生分类及持久状态保持断言，不能报告为授权服务实际故障。错工作区在网络前拒绝；持久 intent 写入后通过新进程恢复，不修改凭据有效期。

真实刷新请求仍走原生 HTTP；收到服务端原 sealedDelivery 后，先用生产加密及 grant 校验确认准确设备/目标/operationId，再仅丢弃本机交付并报告网络丢失。独立服务端只读记录核对只发生一次轮换。冷进程通过已固定证书的桌面具名 LAN-forward 入口，使用同一原 POST/body/token 查询幂等结果；核对原密文摘要、原回执与唯一轮换，不假造 GET 接口，不签发新操作。

收尾仅正常撤销本任务新授权，确认服务端及桌面状态后移除本任务模拟器。共享服务、原模拟器与旧绑定保持。源码、辅助检查、真实原生/服务端结果与交付分别记录，不以本页或构建成功作为验收。

本次四阶段官方 Native 汇总分别为 1 通过、0 失败、0 跳过。真实服务端只轮换一次，第二次 HTTP POST 只返回同一原操作、原加密回执，版本仍为2；受控408/429/503来自独立测试传输，并非服务端实际故障。原工作区错误在网络前拒绝。任务专用授权已由正常桌面界面精确撤销，实际服务端/桌面均撤销，签名请求403，专用grant/claim已清；原五绑定、七张数据表、原模拟器文件与桌面草稿保持。

最初独占模拟器首启桥接、动态安装容器路径、重复业务环境配置及审批等待造成的失败按原件保留。构建产品路径固定到冻结App；自定义JSON只放 `EnvironmentVariables`，从 `TestingEnvironmentVariables` 去除重复业务项后完整运行配置逐值相等，不放宽生产URL或目标。生成身份但尚无offer/claim的等待失败由具名恢复方法沿同一ready/identity继续，公钥摘要及DPoP thumbprint须原值相等，禁止重建身份或盲重放已有claim。

代码和Native源指纹分别关联唯一台账；真实hold阶段由Root在补齐可核实人类授权后通过原正式审批执行，其他阶段由请求Terra medium的测试执行方完成，实际模型/速度遥测限制如实记录。不同测试进程使用各自匹配f06App的模块，不混用ABI；最终源码的相应方法保持相同逻辑，不声称最新主线整包重新部署验收。所有专用模拟器和无依赖展开产物已按阶段规则回收，保留最小证据与必要包指纹。
