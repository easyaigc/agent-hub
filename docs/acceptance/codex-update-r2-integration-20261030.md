# 冻结 R2 与更新恢复的运行集成

候选制品核对发现，根目录通知观察脚本已包含 R2 的 producer 检查，但仓库跟踪的 resource 副本仍旧；标准打包器复制了新 helper，造成源码到包字节不一致。该候选仅私有保留，不发布。现同步规范副本，并在打包前拒绝任何不一致的既有 helper 副本；负向回归要求拒绝构建、保留原件且不产生 ZIP，避免以后由构建静默掩盖源码漂移。

本轮输入固定为已部署 R2 `3ff706b0d29d26a92dd0a14d8c09b8f452377e06` 和 PR #73 合并主线 `da2c4898545f7c9c566475d45ca9617c071f7753`。不读取或复制相邻 R4/R5 活动 WIP，不代做其建议修复；当前 main 的移动端及其他业务源码保留。R2 ZIP 的来源与 SHA-256 见[前置记录](codex-update-resilience-20261030.md)。代码集成、规范合并、统一制品、Windows 独立验收和正式部署是不同节点，不能由清单或代码相似性替代。

桌面通用连接保留 main 既有 publisher 契约；R2 producer 自己的签名、Store、父子进程和私有状态检查保持。producer 的 `trustedPublisher` 只属于该固定 helper 响应，不加回通用桌面身份接口，也不放宽既有 owner/DACL。账号历史元数据不成为新的机器连接拒绝条件。

来源已用旧 owner 包 `04604128…` 的旧 C# `00067a68…`，在普通 Main 中单次执行原固定 preflight，12.341 秒退出 0，目标配置和所测输入保持；新 helper cache 目录/文件为当前 User owner。它只证明旧输入的 Native 初始化和只读 ACL，未捕获逐 helper PID 关闭证明。该次执行方实际模型/档位无法核实，不能计为已核实 Terra。当前 C#、读取器及执行输入已变，不能沿用为本轮 Native 或 reader 通过。

来源人类反馈“已恢复正常”按设备/路线未明确的原连接重试保留，不能扩大为手机全流程、永久更新、旧 history 兼容或 wx 身份窗口通过。正式 R2 继续在线，本轮不强退原 Codex、不改网络、身份、授权、配置或回执。

最终统一包必须绑定实际合并主线和公开同步树，核对五个实际 ESM 组件及原生资源；此前私有 `869e2102…` main-only 隔离候选不发布、不用于覆盖 R2。来源随后隔离验证新 Native 前置、旧布局、只读 reader 旧路径发现与受控子进程退出后的后台恢复，再核对最新正式部署差异。没有真实安装更新窗口时，该项继续单列未验。

Gitea Linux workspace 曾在冻结 R2 的跨轮次退役用例失败：用例隐含成功退役前提，而 Linux 明确不实现退役并保留原始 Trace。现对 macOS/Windows 显式要求两次 `retired` 后保留原抑制断言；Linux 单列要求 `unsupported-platform`、原始输入字节保持、紧凑存储推进至最新轮次及最新读取正确。没有改变产品逻辑、退役策略或支持平台，不把 Linux 的辅助存储检查当作 Native 退役通过。

## 附件 ctime 用例的输入前置

PR74 的绿色 PR CI 与其后 main CI 是两次实际执行。后者在附件 metadata 用例末尾的改写后哈希断言失败，实际为原哈希、预期为新哈希；日志没有前后 ctime，不能把同刻度解释当作已经证实的根因。该分支的附件产品与用例均未被运行集成改动。

用例已有有界 `mutateWithCtimeChange`，但末尾改写尚未使用它。现复用该夹具并显式断言 ctime 实际不同，然后继续原有新哈希及旧版本拒绝断言；既有缓存命中、元数据重读、文件替换和下载摘要边界不变。仅完善测试输入，不改产品、预期或产品时限。原失败回执保留，后续检查按实际执行分别记录。
