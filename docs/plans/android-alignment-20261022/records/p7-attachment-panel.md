# P7 附件面板与最近图片档案

## P7-3b 实现与 iOS 对照

对照 iOS QuickAttachmentViews / RecentAttachmentPhotos：Android 使用带关闭标题的原生底部面板，最近图片、来源收件箱（有待收内容时）、拍照、选择图片、选择文件、显式粘贴、清空草稿按分组和图标呈现。88dp 图片默认横向快选，最多30项，缩略图最长边180px；只在显式点选后读取原图并进入加密原稿，发送时才上传。没有展开开关或提醒设置。短视口滚动保留标题及关闭入口。

原面板捕获完整草稿目标、导入代次和错误代次；释放 Dialog、主窗口重新获得焦点并经过一帧后才执行原动作。文件选择与图片/相机请求一样由 Session 保持，Activity 重建不改原请求；取消、重复/旧回调、切换及返回目标不会消费新请求或覆盖新错误。文件使用真实 ContentResolver 有界读取，重复URI去重；多入口互斥。清空只处理仍有效的原稿，保留生成设置及已提交操作，使旧导入代次失效；旧文件的数据清理另属后续存储工作。

Android 仅请求图片读取，按 API 分别声明旧版读取、图片读取与部分选择权限；不请求视频、音频或所有文件权限。权限未取得时仍可使用系统选图器。完整/部分状态每次恢复重新检查；面板暂停或后台停止照片观察和刷新，取消旧读取，返回后重查。当前 Android 首次请求需点面板内“允许读取照片”，iOS 打开面板即触发首次请求；这项交互差异与完整权限矩阵保持待对齐，不能宣称 UI07/F71 整项关闭。Android 原生授权与重选边界参照[部分照片访问官方说明](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)，读取与缩略图参照[媒体存储官方说明](https://developer.android.com/training/data-storage/shared/media)。

iOS 输入框外的最近新增提示、基线/忽略记录仍待实现；本次完成的是面板内最近30图与显式导入。文件/照片/相机跨进程结果、URI授权、相机私有临时明文和孤立文件仍未关闭，不将 Session 的 Activity 重建保持当作进程冷恢复通过。

- 新手机、API26、API37 各47方法，最终同一产品APK、runner及398个原生/核心/协议输入核对一致。每环境45项辅助和系统选图/文件选择器真实取消2项，原正文/附件/设置与默认存储保留。文件/图片入口在面板释放后实际启动，未选择不明文件或照片。
- API37 受控媒体库方法1项：本次仅自有模拟器预先确认媒体库为空，插入36个本方法自己的图片，独立读取媒体时间与ID排序，验证最近30上限、180px缩略图、提供者更新、原生点击及加密原稿像素/持久化；删除仅限这36个准确URI。临时完整照片权限的原状态和flags恢复。来源为同一验收App UID，不冒充跨App或模型读取。
- API37 独立来源APK → 新面板 → 实际系统选图 → 原请求回调 → 原草稿方法1项本次通过。来源不同UID，不直接授予该照片URI；系统隐私别名、像素与加密数据沿原媒体ID核对。未上传、未发模型输入。
- 暗色附加视口2项：API26字号2与API37字号1.3，分组/图标/行触达、滚动至清空、关闭和原稿保持通过；原生窗口截图已检查。真机截图实际为横屏，仍不替代API37横屏验收。
- 三环境分别重启同一独立Host状态，原模型图片回复只读回读3项通过：同一原owner、原轮次摘要不变、单输入/最终答复与空闲控制正确，全部请求GET。不是再次发送图片，也不是相机JPEG的模型验收。

## 失败与修复

第一批面板验收器直接查找尚未进入懒列表视口的“清空”，且旧选图检查允许 pending 仍为空时立即结束等待；捕获脱离窗口的Compose可点击节点还在框架的声音处理层抛错。这些失败未计通过：改用父列表滚动定位、等待真正启动，并以原请求及实际旧窗口移除核对失效边界。新增文件选择器的具名系统owner检查缺少包可见查询，补准确OPEN_DOCUMENT查询后重验。

受控媒体库首轮发现最近排序不符；改为对时间和ID逐列明确DESC，并由独立查询的原始元数据在验收器排序比较。旧失败保留，修复后原生媒体库及三环境完整47方法重新验收，未拿先前包的通过代替新包。后台照片观察缺口在代码复核中修复；完整原生后台/权限撤销矩阵仍待补。

复用 P7-2c 完整根检查的616/620未变化输入；4个原生目录输入及平台文案由本次原生/生成与契约检查另验，没有声称新跑整次 pnpm check。跳过1/24/22仍不是Windows原生通过。主线另发现问题页语音恢复3提交，作为后续I3源对照登记，本批未导入、不算Android通过。任务/项目业务继续暂缓。
