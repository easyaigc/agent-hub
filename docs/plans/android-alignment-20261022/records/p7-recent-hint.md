# P7 最近新增图片提示与忽略记录档案

## P7-3c 实现与共同断言

对照 iOS RecentAttachmentPhotos / RecentAttachmentHint：Android 完整照片授权下在前台有界观察64项基线，展示最多30张最近图片，复用共享 canSuggest。首次读取、权限变化后的首个基线、部分授权、未知时间、未来/超过十分钟或已忽略的图片不自动提示。当前提示按iOS规则保留，直到成功添加或显式忽略；后台关闭观察、读取与提示，返回按原基线重新核对，不自动导入。

提示沿用48×52dp缩略图、正文/说明、添加及忽略，预览仍只走有界缩略图入口；点击添加后才读取原图。关闭预览、主窗口重新获得焦点并经过一帧后处理准确原草稿。原导入代次、错误代次及完整目标保持，原文件和元数据持久化确认后才忽略原图片；旧提示/旧表面及旧导入不能清除新提示或新草稿。原提示的“忽略”只处理提示，不取消已明确发起的本地导入。重复回执不改变已忽略项的原顺序，与iOS的256项上限及淘汰规则一致。

忽略记录使用独立原生子仓库的Keystore/原子加密保存，严格检查版本、字段、重复及条目上限。读取失败保留原加密字节并阻止空记录覆盖，面板显示准确说明及显式重试，手动选图仍独立可用。偏好冷读不等同照片/文件/相机原URI或结果冷恢复。照片源通过窄接口注入；测试用合成变化/权限/时间源明确标为辅助，不能冒充物理图库或真实模型。资料库版本/提供者、完整权限及迁移矩阵仍在P7剩余范围。

预览期间暂停桌面建议读取/续租，并推迟外部附件收件箱展示；预览关闭后恢复原阅读表面，来件不改变当前草稿。iOS程序和共享核心本批未改，沿用I3已编译基线；完整iOS原生及全状态对照继续单列，A6暂停未执行。

## 验收与指纹

三环境各59项有界结果：附件/相机/选图/粘贴/收件箱/本地化与文案回归、提示基线/权限/过期/旧表面、预览与原稿、迟到导入/错误、记录损坏与重试、外来文件延后展示、桌面建议租期叠层。每环境56项在同一最终产品APK及相关源/辅助方法严格匹配复用；API26截图路径修正后，三环境文案截图类各3项另跑本次通过，共168匹配+9当前。失败整批不当作整批通过。

API37独立来源APK在已确认空的自有模拟器媒体库增加唯一受控图片，不直接给接收App照片URI授权；实际媒体变化/前台返回、提示、预览、显式添加、原图像素/原名/加密原稿及忽略记录确认通过。临时完整照片读取权限的原状态与flags恢复。另以最终包重验媒体库36图/30上限及独立来源系统选图各1项。来源与权限方式分列，不计完整系统授权弹窗或物理相册通过，没有上传或发送图片。

三环境各两段真实App进程：明确忽略后，进程结束，再由同一设备Keystore解密同一原记录，确认加密字节不变且已忽略图片不提示。照片ID源为合成，进程/PID、加密存储和原记录核对为本次原生事实。新手机/API26保留原写入回执并只读重核，原忽略操作未重放。不同runner的复用逐一匹配产品与执行来源：原写入类只有未执行的读取断言变化，其余变化均是无关验收类；实际生产/核心/协议、共同helper及已执行方法不变。

暗色附加两项：API26字号2、API37字号1.3的提示/预览/下滚添加/原稿保持通过，原生截图已检查；大字号预览的添加入口通过滚动到达。真机实际视口另记，不替代API37横屏。三环境同一已完成模型图片回复，各冷Host GET-only回核一次：原owner和原轮次摘要保持，原输入/最终回复及空闲控制正确，没有重发原输入。

共179辅助、9原生平台、3原回复只读，191份默认草稿/附件/代次及最近图片偏好保护证明；1682双语键。新增模型0，累计220/P4 205。按来源分别记录，不关闭完整F71/P7。

## 失败、匹配与后续

首轮六项中五项通过；旧导入组合检查错误假定新图片自动替换当前提示，iOS实际保留当前提示直到添加/忽略。改为先显式忽略正在导入的旧提示、再产生新图片，验证旧回执不能消耗新提示；原失败保留。冷读首轮的解密及字节核对已通过，验收器却对带转义的JSON做普通URI文本搜索；改为解析字段，手机/API26只读原记录再验，不重写忽略。一次验收代码局部lateinit引用不被编译器支持，修正后才运行新runner，无通过计入。

旧文案检查仍期待“添加文件”及弹出菜单，更新为iOS当前“选择文件”与面板滚动；API26 Compose截图不支持Dialog，改独立PixelCopy路径，再单独重跑文案类。产品、源码和每次APK/runner均保留，未把截图问题归为产品或设备错误。最后一轮其余56项逐方法/来源匹配，文案类本次重跑，失败检查点保留原范围。

复用I3完整根检查；全部非Android、非文档的程序输入未变，本批原生、1682目录、移动契约、审批边界与文档格式另验。没有声称新跑完整pnpm check；1/24/22跳过仍不是Windows原生通过。首次照片权限节奏、部分/撤销/提供者/旋转/IME/全语言AX、原URI与相机输出冷结果、存储迁移/清理和语音阅读继续；手机独立冷观察APK、蜂窝/VPN、API37横屏及历史人工项不移除。任务/项目业务继续暂缓。
