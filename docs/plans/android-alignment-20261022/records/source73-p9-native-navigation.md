## 原件、默认路径与收尾

Cold62、reading 夹具的 12 项及 P8 六个夹具的完整原件／密文／九 stat 保持；共享 no_backup 父目录只保持身份，允许新增夹具引起的成员和时间变化；后续方法还保护此前每项 P9 run 与 namespace。首次 Main 仅创建已具名的空默认目录及零长度 inbox writer 锁，未出现默认业务记录；后续 `voice-recordings-v1` 仅 ctime 改变，来源是 `VoiceRecordingStore.kt:53` 对同一空目录再次 chmod，目录身份、其他字段和空成员保持。没有采用默认目录前缀整体豁免。

每方法 started／completed 证明核对精确 coordinator、parent scope、两个 Session、Store 的 join、IO barrier、writer retire 与 shutdown request；默认资料检查通过。下列证据仍明确 false：默认启动 runtime retirement、全部私有默认 handle 关闭、物理 executor 终止、外层 JUnit 超时退出与进程退出。known owned 工作结束不能替代这些门槛。

一次旧采集器 appops 格式解析在 Native 前停止，另一次包装器把路径误传成字典参数而在调用设备前退出；均保留原中止记录。确认未执行 Native 后才修正各自辅助入口，不重放已提交的操作；原业务断言、失败和未知状态未被改写。
