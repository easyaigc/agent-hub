## Immutable original and scope

Each fixture creates a new synthetic WAV and a new local unknown-attempt record. No desktop operation is submitted or queried. All complete target/account metadata, certificate, manifest, unknown receipt, attempts, exact raw persisted original row, all decrypted WAV bytes and metadata/draft/version are compared. A successful explicit local close may append its local terminal; it cannot change the original evidence. Host and microphone factory calls throw and are counted. RECORD_AUDIO retains its initial actual state; no permission launcher is mounted.

Resource states and asynchronous workers are **injected gates**. They test the actual UI/controller/durable original boundary, not JNI, Vosk model loading, downloads, acoustic correctness, absence of arbitrary network traffic or a complete microphone audit. The parent independently runs the real default-engine selectors from stage30. Synthetic workers deliberately remain in NonCancellable scope until released: ending wait must not hide the panel or enable a new action before that exit. The eventual cancelled worker cannot publish a synthetic transcript or durable local result.

Keep each fixture directory, encrypted original, immutable `original.json`, local-terminal audit and its listed lease-specific Keystore alias until the parent exports and verifies the necessary evidence. Then remove only this lease's resolved fixture runtime/alias; never clear application data or touch another namespace. This child creates no device runtime, APK, audio recording or downloaded model.

## Stage32 late-success coverage correction

The historical `recognitionBusyControlsAndEndWaitingRejectLateSyntheticText` gate calls the checkpoint and throws before returning text. Its unchanged default branch proves cancellation, actual exit and no result; it cannot prove rejection of a successful late return. Two additional short-profile selectors now require an actual synthetic SavedVoiceText return, and an observing wrapper must receive that successful value before forwarding it to the production caller:

- `actualSuccessfulEngineReturnAfterOwnerInvalidationCannotStageOrFill`: invalidate the original local owner while the engine is held, then return success without calling its checkpoint. The production post-return guard must reject staging and draft fill.
- `actualSuccessfulEngineReturnAfterEndWaitingCannotStageOrFill`: end waiting through the real UI, then release a NonCancellable synthetic engine to return success. The production generation/cancellation guard must reject staging and fill; the panel remains busy until actual exit.

Both retain the bilingual/theme/native-window matrix and exact original/row/WAV/metadata/permission checks. A busy locale change is attempted and must be rejected; the test does not force an impossible locale change through reflection. Zero successful or forwarded returns fails the new vector instead of counting a pre-return cancellation as late-success rejection. These are synthetic boundary vectors, not recognition or native execution evidence. Parent owns execution of the original five and these two cases separately.
