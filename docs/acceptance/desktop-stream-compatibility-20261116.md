Adapter 以实际共同数据契约验证状态流，保留新增字段；v11、v13 与同结构演进均可读取。跨版本 patches 不应用到旧基线，先只读补完整快照。owner、准确 Host/thread、修订链、执行方法版本、提交前持久化屏障和去重均保留。真实损坏结构会快速返回连接检查错误；iOS 保留原连接操作 ID 和草稿，结束本次等待，下次显式发送先查询原结果。晚到但没有明确错误的 owner 继续原有有界等待。

## 本轮失败与恢复边界

首轮原生运行因模拟器 x86_64/arm64 模块前置不满足而执行零测试、零输入；限定任务独占 arm64 后恢复。首次新建完成后的测试错误地假定默认推理档位为 xhigh，保留失败，不把 null 解释成 xhigh；在同一已确认目标上显式选择 xhigh 补验，未重放首条。设置控件的 AX 选择失败及一次构建主动中止均先经原 owner／回执确认零后续输入，再修正测试选择器；最终按本次实际模型目录索引选中 xhigh。

旧连接夹具另有可选 usage 探测未支持和键盘布局断言失败，均保留原失败；连接恢复验收使用仍严格鉴权／校验目标的专用夹具和正常收起键盘流程，键盘布局问题不冒充已修复。完整检查初次遇到环境 umask/Xcode/JDK 及历史 transport 夹具缺少空 turns 的问题，分别修复环境或夹具并复测，不放宽产品状态契约。

最终错误文案只说明原操作与输入已保留，不推断未知旧输入尚未发送。正向真实 v13 场景按该文字差异的局部依赖等价复核复用，错误与首条提交边界在最终文字上重新执行；正式运行包另外核对 ESM 全依赖指纹和新进程 owner。

主线交付整合保留较新的持久化打开回执与禁止重复导航机制。新增的兼容错误／普通打开错误跨重启回归，首次完整检查在 1038 秒处发现具体兼容错误被恢复器替换成通用提示，原失败保留。恢复器现保留已持久化 outcome-unknown 的有效错误原文，仅将未完成 opening 转成通用未知状态；准确目标、原操作与不重放守卫保持。当前集成的检查与 CI 按新源码另记，不把此前已部署候选的真实 DEV 证据升级为当前整包通过，也不因此改动正式 Host 或手机。
