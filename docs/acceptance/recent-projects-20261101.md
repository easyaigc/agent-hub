# 最近项目（2026-11-01）

## 范围与实现

F26／UI02／UI04／S03／S13：iOS“选择项目”在“不选择项目”之后显示手机本地的“最近使用”，最多五项，最近优先。点选项目开始新聊天、主动打开项目内聊天时更新顺序；重复使用前移，取消、无项目及自动恢复不记入。原客户端完整项目列表保留，点击最近项沿用同一新聊天入口，不自动发送输入。

`SavedSession.recentProjects` 为可选字段，旧存储无需迁移即可读取；仅记录项目 ID 顺序，通过现有手机本地持久化保存，不新增 Host／Relay 接口或上传。按 Agent／Host／workspace／runtime 隔离；Codex 历史账号变化不改变机器范围，其他 Agent 保留原账号隔离。连接地址和项目名称不作身份键。最近项目的名称从当前目录取得，已移除项目不显示。

iOS 原生分组列表沿用系统主题、动态字体、44pt 点击区域及中英文文案。Android 此增强待对齐，不将其已有创建能力或其他平台结果记作本次通过；A6 其他暂停范围保持。
