# 已结束任务的问题回复权限恢复（2026-11-26）

关联 F58。当前功能状态只在[唯一功能清单](../plans/android-ios-alignment-20261107/progress.md)维护。

## 根因与修复

原桌面共享服务的轮次读取不返回 follower 的 `turn.params`。已结束任务的问题回复因此无法取得原权限而拒绝；普通消息沿电脑当前默认权限启动，所以仍可发送。

Adapter 现在从同一 live owner 指定的官方历史中，只读恢复准确 Thread/Turn 的原权限，验证来源、会话归属和轮次；审批策略、审批者、完整可表示的沙箱、目录、网络及工作目录随回复组成不可变快照。提交前再次核对当前 owner、原问题和轮次。不能完整恢复的规则仍拒绝，不改用当前默认权限，不扩大原任务权限。运行中问题、普通消息、旧 IPC 及旧回执的既有流程保留，手机协议不变。

## 原生交互与独立权限核对

使用专用 iOS 模拟器的原生 App，通过固定证书验证的真实 HTTPS 连接 Mac Mini 64G 原桌面；回环代理仅转发真实请求，不合成业务响应。新建单独合成任务，原权限选“帮我批准”。任务提出异步问题并结束后，App 选择答案并提交一次，显示答案回复；随后从输入框发送一次普通消息，显示普通回复。主协调逐张核对两张原生截图，并独立查询 Host 三条已完成回执；目标机另从官方记录确认三轮各一个输入，新增两轮、没有重复或额外输入。原业务聊天始终只读。

目标机核对准确 `session_meta.id` 与三个 Turn 的完整原字段：审批 `on-request`、审批者 `auto_review`、沙箱 `workspace-write`、`network_access=false`、两项临时目录排除均为 `false`，原工作目录和只读例外保持。受限文件系统仍为根目录只读、项目与临时目录可写、项目内 `.git/.agents/.codex/.aws` 只读；`active_permission_profile` 均缺失。答案轮原始 JSON 仅将完全相同的项目可写条目由两次去重为一次，有效权限不变；普通消息轮与原轮原始权限完全相同。三轮有效权限摘要均为 `cf635413092a3bdfbe334e80ad590146f4029bfa5b5cd5b182279b1482e720a4`。
