This adds only NativeMigrationTreeGrantPreparationTest.kt and this workline's documents. It does not alter product migration UI, the three Stage16 picker methods, Main, the P9 router, manifests, providers or a generic command interface. Private compilation reuses the verified Stage16 frozen delta, preserving all 658 expanded parent fingerprints. No device/ADB/install/Activity/system-UI operation is performed in this workline. Two native methods are prepared; they are unrun here. This is environment preparation, never product migration acceptance or real DEV.

The acquisition method uses no Activity rule or automatic foreground helper. Before Main it requires an explicit parent-held preparation lease and migrationTreeMainLaunchReleased=1, rejects readable/partial P9 router material through the pure file-metadata preflight, rejects a live P9 binding or an existing Main owner, and requires the actual system Home baseline. It does not decrypt, release, clear, archive or repair any P9 record. The current sealed cold lease remains the parent's responsibility. Missing or failed preflight means Main stays unopened. The audit method never launches an Activity and never changes grants; its invocation must also omit any external runner wrapper that automatically opens Main. This code cannot prevent an external launcher from opening Main before instrumentation. Even audit/install scheduling belongs to the parent: instrumentation can replace an existing target process, so it must not interrupt the sealed P9 owner. No device action is authorized for this workline.

After that gate, the actual independent debug acceptance MainActivity owns an original ActivityResultRegistry registration with ActivityResultContracts.OpenDocumentTree. The operation ID is an explicit canonical UUID supplied by the parent and becomes its immutable registry key. No synthetic result, replacement registry, test provider, shell launch, shell permission adoption or manual permission injection is used. Any inherited UiAutomation shell adoption is dropped before permission checks. Target package, App UID, runner signature and installed APK hashes are recorded. The resolved DocsUI must be a different-UID system package, and its actual visible root must show the exact UUID folder before grant input. The helper never uses a test Activity in the runner package as the caller.

The allowed tree is computed exclusively as content://com.android.externalstorage.documents/tree/<encoded primary:Download/agent-hub-picker-RUN>. The initial URI is the corresponding document URI. RUN must be the exact new UUID directory authorized and precreated by the parent for this task; do not point it at an existing unrelated directory. The parent observed this folder's breadcrumb and the real USE THIS FOLDER control on fresh API37, external TREE probe 3d00626f-726c-4a8f-a4e6-d8442da2feb4. This external shell observation produced no App grant or callback. No confirmation-dialog ID or text is guessed. Without those controls, automated input stops and the method only waits for its real original callback. The parent may observe and confirm that same original prompt under its lease during the bounded wait. Timeout or any UI failure with an outstanding result preserves the registration/caller and an unknown receipt; it never relaunches. Activity/process survival after runner exit is not assumed and must be checked by the parent. A late real callback, if the original runtime survives, can finish only its original operation file.

The actual callback must return exactly that tree authority and document ID, with no query/fragment or broader root. The real App UID must already have temporary read/write URI permission. The persisted list must contain exactly this one tree and no unrelated/broader URI. An unrelated baseline grant is preserved and causes refusal; there is no broad grant/revoke/cleanup operation. No directory or document is created, opened as content, written or deleted by this helper. The owned empty directory and exact grant are intentionally retained for the separate product picker tests.

An app-private operation file is reserved once before launch. Its App/UID/APK identities, request ID, initial URI and expected tree are immutable. Partial, pending, cancelled or rejected originals are not automatically replayed. A new operation key also refuses any other unfinished/unknown original or partial receipt for that same UUID tree; changing keys cannot evade the first request. Validated callback facts survive later state updates. Duplicate callbacks are ignored. A complete original receipt plus a matching live grant can be audited/reused without another picker. Permission alone is not claimed as original App-callback provenance. The audit writes a separate observation and succeeds only when both the exact empty-tree grant and original real-callback receipt are ready. No source fields, passwords, attachments, old operations, model task or Host command enter this environment record.
