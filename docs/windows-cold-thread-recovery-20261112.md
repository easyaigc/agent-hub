初版冻结源码为 `e4a397c99da5755e03f0f47dd36edd4c8850643c`，Windows 运行清单 SHA-256 为 `50b465f20cbb706e34a8e11304f058c57085aef90d957dbda60aa3bc47d7a85f`，实际准备桥接 Adapter 摘要为 `b82293ef80a0c8de971e87027a88f1f7cf9c9b06a1f17071da469bc41be1d7db`。该初版保留真实原 owner 和一次输入证据。随后修复把打开意图和结果写入 Host 私有持久账本，故新候选需单独验证新的打开 ID 和重启；不能声称补回旧进程中已经丢失的记录。

早期一次隔离目录的所有者不符，产品拒绝写入；保留该拒绝，使用原生流程另建新的当前用户私有目录。外部官方接口准备的零 Turn 会话未进入 Host 目录，读取返回 404；未改写目录或绕过准入，转用确认未归档、无活动且历史仅用于验收的原会话，早期尝试未发送任何产品输入。正式 Host 和原桌面未被重启或升级。双端沿用现有会话恢复能力，本项未新增手机真机验收。
