# Codex / EasyWork 远程接入逐项验收清单

## 外网与弱网连接回归（2026-10-20）

Tailscale 可达不等于已验证外网工况。每次记录手机接入方式、电脑接入方式、实际路径（直连／中继）、RTT、限速、故障注入与实现指纹；本地直连、合成限速、真实蜂窝分别记证。`IOS_SIMULATOR_ID=<dedicated-device> pnpm test:ios:slow-network` 使用真实原生 URLSession 与 XCTest，注入 128 kbit/s、600 ms RTT、十页目录及超出 35 秒期限的读取停顿，属于辅助证据。

| 场景                   | 断言                                                                      | 本次真机状态 |
| ---------------------- | ------------------------------------------------------------------------- | ------------ |
| 首次进入大目录         | 当前对话先于完整目录读取；记录首个工作区请求至历史开始、首字可见的耗时    | 未验收       |

截图中“未能取得此对话的最新进度，当前显示缓存”表示正文同步未得到有效进度，并不单独证明 Host 网络断开；需分别核对 HTTP 连接、桌面 owner 和历史读取。不得用加长所有超时或隐藏错误作为验收通过。

建立日期：2026-10-11。以 Agent Hub 原有 Codex 远程功能为基线，用同一份清单验收 EasyWork；用户真实 iPhone 是最终验收设备。先处理切换对话的失败，再按顺序逐项执行、修复、复验。模拟器、编译和接口检查分别作为辅助证据，不替代真机结果。

## 记录规则

- 每项分别记录 Codex、EasyWork 局域网、EasyWork 中继的结果；换通道后核对同一完整目标及 Thread/Run。表中初始状态均为“未验收”，历史专项记录不自动变成本次通过。
- 状态只使用“本次通过 / 复用通过 / 失败 / 未验收 / 不支持”。“不支持”必须由实际能力和界面核对支持，同时列为与 Codex 基线的差距，不能计入通过。
- 每次通过绑定手机型号、iOS、App 版本和构建、原生源码和程序 SHA-256、桌面版本与实现指纹、账户/Host/workspace/runtime、连接方式及时间。任何相关实现变化都必须核对复用条件或重新验收。
- 一个功能可含多项断言；所有断言完成才勾选该项。模型任务必须核对手机界面、原桌面权威状态、实际模型用量、操作回执及副作用次数。只读场景不得为验证而重复发送旧输入。
- 只在专用验收对话/项目执行发送、停止、归档和恢复；保留用户现有聊天、连接、密钥、草稿、附件和 outbox。未知结果先按原操作 ID 查询，不自动重发。
- 私有日志、截图、容器备份、设备标识、凭据和真实正文放在忽略的 `.local` 或桌面 `release-e2e`；公开文档只记录脱敏结论与摘要。

结果表模板：`编号 | Agent/通道 | 状态 | 时间 | 实现/环境指纹 | 私有证据位置 | 失败及复验说明`。执行记录见 EasyWork 真机结果（本地文件 `docs/acceptance/easywork-iphone.md`）。下表本轮状态仅指用户真实 iPhone 的 EasyWork 局域网连接；Codex 与中继未执行的场景仍为未验收。

## 执行顺序与完成标准

1. P01–P05：保存现有手机数据和指纹，复现并修复切换失败；长/短/正在运行会话复验。
2. C、H、R：先证明可靠连接、准确目标与历史/未读，再执行模型任务。
3. S、G、A、F：使用专用对话逐项验收；每项失败后保留证据，修复后只重跑受影响场景。
4. N、L：真实手机后台/网络/Host 生命周期验收，最后回归原 Codex。

整体验收只有在适用项均有真机及独立桌面证据、失败项关闭、功能差距明确处理后才能声明通过。当前清单建立不代表功能已通过。历史参考：EasyWork DEV（本地文件 `docs/acceptance/easywork-dev.md`）、原生功能（本地文件 `docs/acceptance/ios-local.md`）、已读未读（本地文件 `docs/acceptance/unread-state.md`）、角标（本地文件 `docs/acceptance/unread-badge.md`）、通知（本地文件 `docs/acceptance/task-notifications.md`）、权限（本地文件 `docs/acceptance/permissions.md`）、任务操作（本地文件 `docs/acceptance/run-reply-actions.md`）、长历史（本地文件 `docs/acceptance/history-pagination.md`）、局域网接入（本地文件 `docs/acceptance/lan-connection.md`）。
