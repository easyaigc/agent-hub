# P7 首次照片授权与拒绝后恢复档案

## P7-3d 对照与实现

iOS 在打开附件面板的 task 中只向 notDetermined 请求照片权限；拒绝后显示说明与系统设置，部分权限保留管理入口。Android 现在在首次打开面板、取得窗口焦点并经过下一帧后请求对应平台的照片权限，不在聊天启动时请求。拒绝后关闭或重开面板不自动再请求，系统选图、文件、粘贴入口仍保留；部分授权管理是显式操作，不自动读取原图或上传。

Android 没有与 iOS 完全相同的 notDetermined 状态，因此按 external / images / selected 原生权限组保存独立加密尝试记录，写入成功后才启动系统请求。记录带版本、权限组和尝试标识；未知版本、权限组不符、无效内容或存储错误保留原文件，阻止当作首次请求重写，提供显式重试。尝试标识表示曾准备请求，结果不确定时也不自动重放；不等同操作系统已授予或已拒绝权限。升级前已有 OS 决策但无本地记录的完整迁移矩阵仍待验。

同一 Session 一次只持有一个请求，原 owner 才能进入启动阶段，同一启动只能消费一次。系统回调在面板外注册，关闭面板不撤销回调；结果仅刷新图库访问状态，不导入、上传或发送内容。Activity 保留与原生回调沿现有机制处理；本阶段没有宣称进程被杀后的原照片、文件或相机结果已恢复。图库面板与提示使用同一窄接口，测试中的合成照片/权限适配器明确标为辅助。

## 本次验收

真机、API26、API37 各四项授权辅助检查：首次尝试先加密持久化、重建后不自动请求、单个请求/原 owner/单次启动、损坏或未来记录保留、已有可读来源打开面板只展示。来源与授权结果为受控适配器，不计系统授权通过。另三环境各48项附件归属、图片、相机请求、最近提示、分组面板、粘贴和收件箱回归通过。

API26 / API37 各一次真实系统首次请求 → 拒绝 → 返回 → 重开无新弹窗，通过系统包、系统 UID、准确调用方包及 UID 独立核对。没有授予照片访问权限，也没有触碰用户手机的授权弹窗。拒绝后的系统设置和选图入口可用，原稿保持，原生 Dialog 截图已检查；API26 下部动作通过滚动触达。API26 保存的是原成功场景及活动记录，后续验收器新增的空格兼容及准确调用 UID 断言在原密封记录上独立重核，没有重放拒绝。

API37 的拒绝 flags 恢复至原状态。API26 旧系统没有可用的具名清 flags shell 命令，保留本任务独立验收包的 USER_SET 拒绝，读取权限仍未授予；不执行全局权限重置、不清 App 数据。该环境变化单列，不能写成 flags 全部恢复。

同一已完成真实模型图片回复在真机、API26、API37 各一次冷 Host GET-only 核对：原 owner、原轮次摘要及单条输入/最终回复保持，没有写请求或重发输入。当前共156辅助、2系统场景、3原回复只读，161份默认草稿/附件/代次/最近图片与照片授权偏好保持证明；模型新增0，累计220 / P4 205。1682双语键保持。

## 过程、失败与限制

首次弹窗检查没有推进 Compose 帧钟，两个 SDK 未取得系统窗口证明；改为原生等待时推进帧。API26 系统包为 Google packageinstaller，已核对系统 UID 后纳入准确允许集。API37 活动记录使用 Hist 后双空格，旧解析未取得调用方，修正为有界空白匹配并增加准确调用 UID 核对。旧失败不删除、不计通过，不据此把产品故障归因于用户。

期间 ADB 中模拟器全部消失，原因为未确认；只重新启动本任务两个准确 AVD，保留磁盘数据，未启动或处理其他 AVD。一轮 API26 回归与新 runner 构建窗口重合，来源配对不作最终证据；保留原记录，构建成功并冻结后重跑最终48项。其他匹配复用只允许生产 APK、所有已执行方法与 helper 相同，差异限未执行的系统验收类；API26原系统证明的新增调用方断言另核原证据。

本批 Android 原生构建、移动契约/目录、审批边界及文档格式另验；完整根检查按 I3 严格匹配非 Android / 非文档程序输入，不声称新跑整套 pnpm check，历史1/24/22跳过仍不是 Windows 原生通过。iOS程序与共享核心保持I3基线，不运行暂停的A6。

生产APK及407既有原生/核心/协议输入完全匹配3d，只新增一个冷读验收类；3d的161项保持其原通过/匹配/调用方重核分类，复用不计为本次新场景。iOS、Host和共享核心未改，模型新增0、累计220/P4205。原文件/照片/相机结果、URI/输出冷恢复仍独立开放。
