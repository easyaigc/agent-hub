# 对话模型与推理强度同步修复（2026-10-26）

关联 F34、S06、UI07／UI08。用户提供的反例为电脑端 GPT-6.1-Sol／xhigh，手机显示同一模型／low。

## 修复范围

- 已有对话的底部模型／强度只使用原 owner 当前设置。模型目录的推荐默认值不代表对话实际值；未读到时显示“同步中／跟随电脑”。
- 手机草稿中的覆盖项保留并用于下次发送，设置面板分别展示“电脑当前设置”和“下次发送”，不再覆盖底部实际值。
- KMP 提供两端共用的展示选择规则；iOS 与 Android 接入同一规则。目录、权限、速度及不可变已提交输入的语义不变。
- Host 用具名只读接口单独查询准确原 owner 的模型／强度；完整消息快照缺失时仍可取得参数，不因此授予控制权限。绑定当前连接与 owner，合并在途查询，拒绝错源、断连后的迟到返回及过期值。
- 完整快照投影与原桌面当前参数读取保持相同优先级，当前模型和强度优先于保留的上一轮设置；明确 null 保持 null。
