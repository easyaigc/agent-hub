## 原因与修复

用户截图对应的实际 Host 响应已保存为私有反例：同一最终消息 ID 的 `readState.latest.contentVersion` 与传给手机的正文摘要不同。原正文包含本地图片链接，Adapter 将链接改写为 `codex-attachment://` 后仍发布原文摘要。手机严格校验失败，无法确认已读；刷新列表不能纠正。

Host 现将阅读位置绑定完整投影后实际发送的正文与状态，并内部持久保存原正文摘要作为栅栏。同一原桌面摘要刷新不回退投影版本；旧页、已被取代的异步投影不更新最新版本。手机仍须看到匹配的最新内容，原桌面与手机的未读状态保持独立；协议字段和双端 UI 不变。
