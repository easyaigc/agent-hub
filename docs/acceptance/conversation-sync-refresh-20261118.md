# 对话刷新同步竞态（2026-11-18）

范围：Codex Host，F17/F18、UI05、S02/S11。iOS × EasyWork 唯一台账、Android 暂停项和 A6 不由本专项接管。

## 问题与修复

用户现场为电脑绿色在线，刷新特定对话后出现“对话同步失败／未能取得此对话的最新进度，当前显示缓存。正在自动重试。”电脑在线与对话进度新鲜性分别核对。

Host 收到原 owner 快照时先更新运行控制并通知读者，完整消息异步投影。事件读取若在投影中间生成窗口，会将内部尚未完成的状态作为 `unavailable` 发布。历史读取还有第二个竞态：先前投影完成之后，模型或队列元数据读取期间可能收到新快照，最终窗口也可能在新投影尚未完成时生成。

候选在指定对话的最近窗口事件响应边界等待投影最多一秒。较长投影仅返回原 epoch/游标、`reset: false` 和空事件；不确认新 epoch、不刷新消息新鲜度、不把缓存标为 live。原投影继续执行，不取消其他读者；完整投影完成后下一轮仍取得权威快照。历史最终响应再加入同目标新投影屏障。

真正失去 owner 仍返回不可用；新投影失败会撤销旧完整投影证明并写入私有诊断，不能在移除失败任务后借旧证明恢复为 live。原操作 ID、未知输入、附件和草稿均不重放。既有四种同步状态及旧完整读取契约保持，Android 共用 Host 修复，但原生结果单列。
