# Agent Hub Android 隐私政策草案

准备日期：2026 年 11 月 19 日。**这是待核对和部署的 Android 专用草案，尚未生效，不代表现有线上网页已经覆盖 Android。** 发布前由运营主体确认实际服务、SDK、通知通道、联系人及用户权利处理方式，再同步中英文网页和 App 入口。

合肥博璀人工智能科技有限公司提供 Agent Hub。隐私与支持联系邮箱为 admin@51easyai.com。Agent Hub Android 是连接您拥有或获授权电脑的 Agent 管理工具；任务在所选电脑上执行。电脑端 Agent 及其模型服务、可选中继和项目任务服务，可能由不同运营者提供。

## 处理的信息和用途

| 信息                                                  | 用途与处理位置                                                                                                               |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 电脑地址、Host/runtime 标识、设备密钥、配对与登录凭据 | 识别您选择的目标、建立授权连接及恢复会话；设备侧使用 Android Keystore 支持的本地保护，不要求提供 Codex 登录密码              |
| 消息、草稿、对话历史、任务状态、审批回答及回执        | 本机展示、编辑、缓存与恢复；主动提交后进入所选电脑及其配置的 Agent/AI 服务，处理范围以实际目标和数据共享说明为准             |
| 图片、文件及相关元数据                                | 显示获授权的最近图片和附件入口、添加草稿、预览、下载或导出；明确发送后才传给所选电脑或服务，不因选择附件就宣称已发送         |
| 音频及转写文字                                        | 按您选择的电脑端、Android 系统语音识别或已支持的本地转写功能处理；文字返回草稿后由您决定是否发送                             |
| 设置、阅读位置、未读状态及待确认操作                  | 本机恢复使用状态、核对原操作及避免重复执行；断线或退出当前等待不代表远端操作已取消                                           |
| 必要的设备/订阅标识与通知状态                         | 在所配置、实际可用的通知通道中生成和投递提醒；具体接收方依连接和通知配置而定，不把尚未验收的厂商推送声明为已提供             |
| 必要的网络和错误信息                                  | 连接、安全诊断和故障排查；您访问的电脑、第三方服务或官网可能处理 IP 地址、访问时间、路径和错误信息，分别受对应运营者政策约束 |

## 系统权限

应用应在使用相关功能时申请权限；您可在 Android 系统设置中管理或撤回。拒绝某项权限影响相应功能，不应强迫您授权无关权限。

| 权限或系统入口                           | 用途                                                                                                      |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 相机                                     | 扫描配对二维码、拍照添加附件                                                                              |
| 麦克风                                   | 您主动发起的语音录入                                                                                      |
| 照片/媒体读取或有限照片授权              | 最近图片快捷入口和图片建议；不同 Android 版本的授权范围不同，系统图片或文件选择器按系统允许的范围提供内容 |
| 通知                                     | 已配置且实际支持的任务与审批提醒                                                                          |
| 网络状态、互联网与支持版本的本地网络权限 | 发现、连接所选电脑、传输您提交的内容和恢复连接                                                            |

## 语音与第三方组件

电脑端转写会把您选择的音频交给目标电脑及其配置的转写服务；相关账号、费用与处理政策以对应服务为准。Android 系统语音识别的处理位置和服务商取决于手机设置、可用识别服务与语言，不能保证均离线处理。用户选择的本地保存音频转写功能使用 Vosk；下载模型会访问 alphacephei.com，模型安装后在本机处理受支持的音频，不因使用本地转写就将音频交给模型下载网站。

当前源码的直接依赖包括 AndroidX/Jetpack Compose、CameraX、ZXing、CommonMark、Vosk/JNA、OkHttp 与 Bouncy Castle，分别用于界面、相机/二维码、正文渲染、本地音频解码、网络和密码学处理。开源代码库不等于独立接收个人信息的线上服务；发布时须核对最终依赖及其初始化/联网行为，并将实际第三方数据接收方、用途和政策链接完整披露。不得用这份直接依赖摘要替代最终 SDK 检测。

局域网直接连接通常无需注册 Agent Hub 账号；可选 EasyAI 中继、Task Hub 或目标 Agent 的登录、成员权限及数据处理由其实际运营者负责。首次向真实电脑及其模型提交内容前，应查看 App 的“AI 数据共享”说明，核对目标和配置。允许共享不等于自动发送原草稿，提交仍由您主动操作；可在设置中撤回该许可。

## 保存、删除和用户选择

本机的设置、草稿、缓存、下载与恢复记录按相应功能状态保存；可通过已有的删除、丢弃、移除连接或导出功能处理相关内容。卸载正式包不会替您删除已发送至电脑或第三方服务的副本。已提交但结果未知的操作需要保留必要回执和原意图，不能以清除等待冒充取消远端任务。

电脑、AI 服务、中继和项目任务服务分别按其运营者规则保存与删除数据。您可通过上述联系邮箱提出访问、更正、删除或其他个人信息请求；涉及第三方账号或由您控制的电脑时，应同时向对应运营者或管理员处理。发布前须核实各实际账号服务的注销/删除入口，不承诺当前界面不存在的“一键注销全部第三方账号”。

发送前请注意目标电脑和模型服务所在地区及其数据处理规则；本工具不保证所有内容均在中国境内或全部离线处理。涉及敏感信息时，先确认您具有相应授权及目标服务符合您的要求。
