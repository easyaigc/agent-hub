# Own the complete EasyWork form action through actual exit

The Compose form previously launched the entire pairing action in `rememberCoroutineScope`, with only the revocable lease added to its context. On pause/disposal the UI releases `connectionBusy`; a claim/install write or HTTP cleanup can still run. That action was outside Session children, migration owners and the IO tracker, so quiescence could finish before it exited. Invalidating the lease prevents client activation, but does not stop or finish the original authorization audit write.

The Page changes only its `perform` wrapper. It now invokes a narrow Session method that admits the original action only on Main while the Session is ready and its migration owner is open. The complete work and saved callback execute once in a Session-owned child with the original action, IO tracker and migration owner context. A registry owner is registered before the lazy child starts, cancels/joins that exact child, and retires only on actual completion. Compose owns waiting/UI; cancellation cancels the child without pretending blocking IO has exited. UI release remains separate and the old stale-form guards stay unchanged.

Registering only a Session child would leave another gap: after a cancelled quiesce, existing recovery waits for migration owners/IO before reopening admission. The action's additional registry owner keeps that gate closed until its blocking IO/finally has actually exited. HTTP callbacks and queued client disposal retain the inherited IO proof after coroutine completion. Claim, grant, candidate, lease input and unknown-result recovery contracts are unchanged; no new attempt, revoke or replay is introduced.
