Agent Hub Help & Support

Connect your iPhone to computers you own or are authorized to use. Browse projects and conversations, continue Agent tasks, and use a configured Task Hub service for project and task management. Codex and EasyWork are currently supported; available controls depend on the connected runtime.

For setup, support or privacy requests, email admin@51easyai.com. Operator: Hefei Bocui Artificial Intelligence Technology Co., Ltd.

Languages

The app supports English and Simplified Chinese. Settings > Language lets you follow the system, choose English, or choose Chinese. Switching changes interface text immediately; it does not translate or resubmit your conversations.

Connect over a trusted LAN

  1. On an authorized Mac or Windows computer, install and open a supported Agent desktop app, configure its model service, and run the Agent Hub Host connection service. Contact support for computer-side setup assistance.
  2. Connect the iPhone and computer to the same trusted Wi-Fi or LAN. Allow Local Network access for Agent Hub. Guest network isolation or firewall rules can prevent discovery.
  3. Open the client selector at the top > Add client > Codex or EasyWork. Use Automatic discovery and select the expected computer. Hosts configured for automatic pairing do not require an Agent Hub account, address or key. Use the computer's QR code or manual connection when its configuration requires pairing.
  4. Check the target computer, open a conversation or create a new one. Review the AI sharing disclosure before submitting. Allowing sharing alone does not send the draft; tap Send again when ready.

Direct LAN mode needs no Agent Hub registration. Desktop/model accounts and any provider charges are separate. Optional EasyAI relay uses external sign-in. Across-network access requires a separately configured trusted network; the app does not supply a public computer connection.

Try a harmless task

  1. Open the side panel to browse projects and conversations.
  2. Tap New Chat and select a project or No project when available.
  3. Send: “Do not use tools or change files. Reply only: Agent Hub connection successful”. Check the response in the app and the same conversation on the computer.

Task Hub projects and tasks

This optional workspace requires a configured Task Hub service on your trusted network and a member account issued by its administrator. Pair the service, sign in with those member credentials, then use the projects and tasks your role can access. The service operator manages membership, task data, retention and account deletion; it is separate from the direct Agent connection.

Voice input

Settings lets you choose computer transcription or local system transcription. If the computer reports transcription unavailable, the app can use the phone system. Computer transcription sends the recording to the selected computer after the sharing check; its configured transcription service handles the audio. Local transcription uses Apple system speech services, on-device when available or using the system's online service. Text returns to an editable draft; it is not automatically sent as a chat message.

Sharing, recovery and permissions

Settings > AI data sharing lets you review and revoke future sharing permission. Already submitted content is not automatically deleted and running work must be stopped separately. Permission scope is shown in the app; following computer configuration permits that target's current and subsequent AI configuration, so verify the actual provider on the computer.

If delivery is uncertain, reconnect and query the original conversation or operation receipt before sending again. Microphone, speech recognition, camera, local network and notification permissions are requested when their features need them. Notifications also require the computer-side push configuration.

Local UI example

Settings > Local experience > UI example shows labeled synthetic clients, projects and conversations. It does not provide live model execution or a complete review environment.

Report an issue or request data help

Include your app/iOS versions, Agent type, time and steps to reproduce. Remove private content from screenshots. Never send passwords, full connection keys or unrelated conversations. Contact us for access, correction or deletion of information we control; contact your own service operator for computer, Task Hub or model-provider data.
