## Closed invocation and input

The runner class is `com.agenthub.android.NativeRealSavedVoiceSpeechTest`. It accepts exactly three `fileAsr*` arguments: `fileAsrLease` (canonical UUID), `fileAsrLocale` (`en-US` or `zh-CN`) and `fileAsrAudioSha256` (64 lowercase hex). Other instrumentation arguments remain normal runner parameters. A `fileAsrPath`, URL, arbitrary method, language fallback or network override is rejected. The selected JUnit method is one of the finite selectors below. Launch methods individually, never the whole class/package: ordering, locale and one-time case claims are explicit prerequisites.

Only `com.easyai.agenthub.android.acceptance` and its `.test` runner are accepted. Wrong install identity fails before touching data, including `.acceptance.easywork`. The lease must bind the actual app and runner APK SHA-256, API26 or API37, arm64-v8a and a 64-bit process. Run each API/language tuple under a distinct parent lease. Build/device fingerprint, process UID/PID, SDK, ABI, actual page size and both APK hashes enter the result; this does not replace the parent's actual device identity record.

The parent prepares these fixed target-app-private files:

- `files/acceptance/P7-real-file-asr/<lease>/lease.json`
- `files/acceptance/P7-real-file-asr/<lease>/input.wav`

Directories must be private, input files owned by the target UID, mode0600, regular and without symlinks/hardlinks. The WAV must be canonical44-byte mono PCM16/16kHz, 0.1–30 seconds, and match the argument SHA. No arbitrary pathname is accepted. Parent retains the original TTS WAV and synthesis tool/voice/version/declared-text provenance outside the checkout. The lease declares `inputKind=declared-tts`; the harness does not synthesize speech or independently prove the source of a supplied recording.

Use these exact declared phrases (the test removes punctuation, whitespace and case only): English: **open the project and show the latest message**; Mandarin: **打开项目，显示最新消息。** Their phrase IDs are `en-open-project-v1` and `zh-open-project-v1`. An incorrect actual transcript fails; the test never injects recognized text.

`stage30-real-file-asr-contract.json` contains the complete lease schema, selectors, arguments and result fields. Use actual device epoch milliseconds for creation/expiry. Maximum declared lifetime is two hours. The first case seals the lease declaration hash. Each case claims a unique immutable intent and cannot be rerun under that lease; inspect its original result instead. An unknown worker/resource exit blocks subsequent cases. A new lease creates independent input/intent scope, not a replay of any desktop operation.

## Actual factory, storage and resource boundary

The harness calls the untouched `VoiceInputController.savedFileFactory` without modifying its default, asserts its real `VoskSavedVoiceSpeech` class, and uses actual Vosk/JNA methods. It never assigns the factory or supplies an engine/transcript double. A filesystem-only ContextWrapper keeps the default assets, native loader and services, while routing model cache and original encrypted storage into this lease's private runtime directory. The model manifest asset is fixed to SHA `70003a068c5ebc69e7babc77e5c3009a36ec4bd0e68714d0e37d96e6c9e92f42`. Actual packaged arm64 native-library hashes, declared dependency versions and model archive/cache fingerprints are recorded.

This is a direct adapter test through the default factory, not the product UI/durable-destination/whole-Session acceptance suite. It creates a new local TTS original with explicitly synthetic unknown-attempt flags. No real desktop input is submitted, queried or replayed. Across every operation it compares the whole key-sorted `PendingVoiceRecording.json()` and the exact persisted row string against immutable `original.json`, and compares every decrypted WAV byte with the declared input. The complete target/account, certificate, manifest, receipt and attempt fields remain included; no DTO/reference equality or field exclusion is used. It also records the original ID, canonical-original/manifest/row/audio hashes, immutable fingerprint and preparation/upload flags. If any original or its immutable baseline becomes unknown, it fails without replacement. Its local action UUID differs from the original ID. The only AgentCommands factory errors if invoked and records its own observed call count; this does not attest that unrelated app traffic is absent.

Workers remain owned until their actual API return/finally and join. Native cancellation records a real stack window, joins the default backend, checks a subsequent real probe and captures `/proc/self/fd` and mapped-model references. These observations are not direct tracing of native free functions or a heap-leak proof. Unavailable reference observation is not changed to zero. No model reference may remain before cache deletion. These tests do not force-stop or cancel any desktop/Host operation.

## Evidence and limits

Each claimed case preserves `cases/<case>/intent.json` and bounded `result.json` under the lease root. The original intent, supplied input and encrypted original remain; model ZIP/staging are removed by the production installer/cancellation and the final model cache is explicitly released. Parent must pull/preserve the unique input/proof and account for this runtime directory and its lease-specific Android Keystore alias after the stage. Do not keep a whole compiler environment as evidence.

A successful method reports **ENGINE_ASSERTIONS_PASSED_RUNTIME_PRIVACY_PENDING**, never a full acceptance pass. Missing models, corrupted models, unsupported/native-load unavailable, missed cancellation windows, invalid input and unknown failures remain separate from acoustic success. No `Assume`/skip establishes a pass. Actual model/recognition results, expected versus actual text, API/ABI and original invariants are separate fields. Model downloads and decoding have separate traffic samples.

RECORD_AUDIO must retain its initial state; the harness never requests or grants it. The recording configuration callback is an observation, not a complete UID microphone audit. UID byte counters may be unavailable and do not identify HTTP methods, audio uploads or connection attempts. A zero delta is not a no-network claim. Parent must supply independent app-UID microphone/phase-specific network evidence, and distinguish an externally blocked decode from explicit download traffic. No `fileAsrNoNetwork` argument can substitute for observation. See the [Android recording configuration API](https://developer.android.com/reference/android/media/AudioRecordingConfiguration) and [UID traffic counter API](<https://developer.android.com/reference/android/net/TrafficStats#getUidTxBytes(int)>).

This preparation has SDK and host contract checks only. No native selector, resource download/load, recognition, microphone audit, network denial, process death or full DEV has run here. The earlier Source35/36 UI/store results and iOS/Windows results cannot substitute. Parent reports RV29 production adoption in Source40; this tests-only patch still requires independent integration into that current source and new candidate fingerprints.
