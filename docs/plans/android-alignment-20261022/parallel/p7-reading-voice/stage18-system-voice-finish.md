# Stage 18: original system-voice finish callback generation

The system recognizer adapter may complete or fail from inside `finish()`. The controller previously read its generation after that call. A synchronous successful callback clears the original and changes generation, so the following timeout could be attached to the now idle controller and incorrectly fail it 15 seconds later. A synchronous failure followed by a thrown exception could similarly replace the original terminal error with that late exception.

The system-provider finish branch captures its original generation before invoking the adapter. It installs a deadline only while that same generation remains finishing, and any thrown exception is fenced by the original ID. This changes only that branch; desktop PCM capture, upload, recovery, discard, migration quiescence, permissions, drafts and providers are unchanged. The current parent's controller has additional migration-quiescence code; integration must preserve those additions and apply only this finish hunk.

Two native regressions extend the existing injected-recognizer fixture. One emits a synchronous final result and a duplicate result, waits beyond the actual 15-second finish deadline and requires the controller to remain idle with exactly one applied text. The other emits a terminal failure then throws and requires the original localized receipt and partial text to survive; the explicit current-draft fill still applies once. These use no real recognizer, microphone, Activity, Host/model or submitted operation. Native compilation is auxiliary evidence, and the methods remain unrun in this workline. They do not establish actual acoustic, OS-dialog, process-death or saved-file phone transcription support.

F33/F42/F56/F58/F64 share original-draft ownership and terminal-callback fencing. Composer and question use the same controller. No product copy, design tokens, system UI or durable schema change. iOS is unchanged; A6 remains paused. Parent owns central feature/design/acceptance manifests, frozen integration, leased native scheduling and real DEV. Current reading evidence is not invalidated or upgraded by this voice-only hunk.
