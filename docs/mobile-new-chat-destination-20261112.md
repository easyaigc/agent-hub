# 双端新聊天项目选择

来源：[GitHub PR #2](https://github.com/easyaigc/agent-hub/pull/2)，上游 `1c770eb80d773dfd3b9ff59717cadc786af30829`。主库候选在现有 iOS 新聊天流程上补齐 Android 交互，并为双端增加已登记路径、刷新及后续项目页。保留按连接隔离的最近项目、无项目草稿、取消和首发行为；选择前复核原连接和导航，第一条显式发送才创建。

| 层次           | 本轮验收                                                                                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Android 模拟器 | API 36 arm64：侧栏、选中目录、最近项目、取消、无项目、能力和刷新分页，原生 UI／会话回归 12 项通过。                                                                                       |
| iOS 模拟器     | iPhone 17 Pro／iOS 26 arm64：最近项目排序、重启和电脑隔离，离线可查看且禁选，显式首发才创建；XCTest 3 项通过。                                                                            |
| 真实桌面和模型 | Android API 36 模拟器 → 本机隔离 Host → macOS 原 Codex Electron：选项目时无写入，显式发送仅一次 prepare 和一次 submit。独立进程核对准确项目、原 owner、唯一用户输入和完成的实际模型回复。 |

路径是原电脑目录的只读展示。选择项目以现有项目注册的目录为准；需要注册新目录时走现有授权入口，能力缺失时在原桌面添加后刷新。

Android 应用 APK SHA-256：`321327cbbf102b133abed0a83ce00621bd4efcd8e9953b979c77900f829903d5`。iOS 变更文件指纹：`3be55539e16d69278f42348c46fa688db35c21cfa74e22170720bd7525f2f629`，三个原生用例共约 99 秒。早期两次真实测试在项目目录核对阶段退出，代理记录为零 POST；最终选用 Host 与原桌面均可见的已登记项目，无需改写目录或重放消息。上游使用其隔离 Windows Host；本轮 Mac 结果不代表 Windows 或物理手机验收。
