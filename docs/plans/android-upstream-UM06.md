公共层处理领域规则，HTTP／SSE、SQLite、密码学、文件和后台传输保留原生窄接口。平台后台传输能力与权限在实现前逐项核对，不把任务调度的自动重试等同安全重传。Task Hub 人类登录独立于 EasyWork 免账号配对；聊天 runtime 账本不能冒充业务账本。

Android 上传由应用级协程持有一次性传输，界面取消等待不取消传输。进程终止后，持久原文件、票据、ID 和摘要仍可核对，但只查询原回执，不重新排队 POST；这与 iOS 的系统后台 URLSession 恢复机制分别记证，不声称 Android 有同一种系统后台传输能力。业务页面、AI 共享许可展示和导航由 UM07 接入；当前领域提交必须经过独立授权接口，不借用聊天许可。

### 当前增量验收与原失败

运行包修复只生成离线候选，未部署、替换或重启正式服务。公共核验为 JVM／Kotlin Native 各47项；Task Hub 跨语言另含12条游标、25条阶段与11条契约向量。Android 原生领域三机各15项通过、HTTPS合成边界各1项通过，均属于辅助证明。设备会话查询和显式撤销仍在新增原生复验范围内。

实际4MiB缓存暴露了两个独立问题：旧大行超出 CursorWindow，以及 API26 在48MiB堆限制下整份JSON解码溢出。现改为64KiB独立认证块、有界SQL读取和流式JSON读写；同一份新格式4MiB缓存已在三机跨实际进程重启保留原内容和新草稿。API37／小米原旧格式4MiB成功迁移；API26有效旧格式小样本迁移通过。API26原大样本认证失败未推断原因，原库与失败保留，拒绝读取／写入且不自动重置的负例通过。数据库规模上限仅是拒绝边界，不代表每款设备堆内存都能容纳该上限。

登录组件三机原轮各1项通过、2项失败；原失败断言同时比较提示文字与已清空编辑值，纠正为准确EditableText比较，后续按新验收器单列。真实Task Hub人类账号验收仍待账号信息和原生界面输入；不将电脑免账号配对改为账号登录。完整业务页面和独立AI许可展示继续属于UM07。
