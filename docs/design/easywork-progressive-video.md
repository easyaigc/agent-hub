# EasyWork 固定版本视频读取

本页记录 INC02 / F77 的实施设计与兼容边界。开发、原生模拟器与真实 Electron 验收、合并和当前限制只维护在 [唯一台账](../plans/ios-easywork-alignment-20261112/README.md) 的 `F77-easywork-progressive-video`，不另设完成数。MEDIA01 已有播放器验收按准确依赖和原范围复用。

## 调用链与兼容

公共 `MediaPlaybackSession`、`MediaByteReader` 与 AVPlayer resource loader 保持一个实现。EasyWork Adapter 覆写现有 `prepareMediaRead`、`mediaBytes`、`cancelMediaRead`，将既有加密请求映射到 Codex Host 的 `attachments:range-read:v1` / `AttachmentReadState` 领域契约。

既有 `resource/read` 和 `resource/download` 增加严格区分的 `read: range-v1` 输入分支，并增加具名 `resource/read-cancel`。旧分支的参数、返回值与权限不变；新分支不接收路径、任意方法或旧传输参数的混合输入。只有实际装配快照服务时才声明能力；旧端缺能力时继续原完整下载。

| 共同语义                     | EasyWork 映射                                                                                                                                 |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 绑定、完整目标及具名资源授权 | 原加密网关先核设备绑定、完整 target 与 `files:read`；每项读取按目标、当前绑定、设备、线程和资源隔离，源记录沿用原传输授权及适用的文档绑定约束 |
| 固定版本准备及查询           | 同一 `readId` 查询当前 preparing/ready；使用共同 `AttachmentReadState`、完整领域目标和原资源标识，不能缓存首次 preparing 为永远不变的写回执   |
| 范围                         | 同一 Range 解析规则；严格 If-Match、206、ETag、Content-Range 与实际字节数；WSS 有界块在 Adapter 拆分，不复制播放器                            |
| 租约和同版续读               | 原十分钟租约与相对剩余时间；公共播放器先释放旧读，再准备新读，版本不同不拼接                                                                  |
| 取消、退出、切目标           | 原读取标识的幂等取消，等待本地准备和在途读取退出，再释放快照和预算；晚到查询不能重开已取消读取                                                |
| 错误                         | 明确区分无能力回退与已授权读取的目标、版本、过期、范围、容量错误；后者有界失败，不降级读到别的版本                                            |
| 完整下载和分享               | 原完整文件 API 只发布完整、摘要验证通过的准确版本；不能将部分缓存作为可分享文件                                                               |

新请求仍走原授权和恢复分类。准备/查询、字节读取与幂等读取消只影响临时读取资源，不产生模型输入；用公共恢复向量核对两端映射。原 `resource/resolve` 与文档解析的不可重放分类保持。

## 桌面快照边界

先由现有文件传输服务解析已授权资源，不接受手机提供文件路径。捕获通过描述符读取的实际大小、文件身份和摘要；准备期间检查取消、容量与源版本，公开 ready 前完成原子固定快照。后续读取只读私有快照，并检查原授权、源版本、快照身份、范围与租约。公共响应不含本机路径或凭据。

预算沿用现有 Host 设计：总快照预算二 GiB、最多十六个活动读取、两项准备和八项并发字节读取，保留有界取消墓碑；准备有期限。撤销绑定及服务退出回收对应读取。平台的私有目录和文件保护须由实际实现成立；没有满足保护条件的平台继续原完整下载，不能仅凭 chmod 声称 Windows ACL 已验证。

## 增量验收

使用任务自有合成视频，不采真实麦克风，不发送聊天或模型输入。真实 Electron 提供已授权资源；如需专用 DEBUG 媒体入口承载该资源，明确记录入口边界，不能把合成聊天行宣称为真实桌面消息。公共聊天入口与播放器未变范围按准确源依赖复用 MEDIA01。

1. 原生模拟器实际首帧与时间/画面推进；确认首帧前没有传完整视频。再次打开核授权与缓存复用。
2. 暂停后拖到未缓存区间再播放，真实桌面观察远端高偏移读取；内联/全屏往返保持同一播放会话。
3. 同版换读、真实租约过期、ETag/源版本冲突、错误完整目标有界结束；区分真实 Host 结果、受控错误和辅助边界证据，不用缩短测试时钟冒充十分钟真实过期。
4. 关闭、切目标、准备中取消后，核原 readId 不再产生字节、快照/预算释放，迟到查询不重新准备。
5. 分享按钮仅在完整版本下载并核摘要后开放；核系统分享面板，不宣称接收方保存。
6. 旧能力回退与既有普通附件按未变范围复用或定向验证，不全量重跑。真实桌面独立核原项目、消息与运行计数，零新增模型任务。

每个断言保存真实源、运行包、调用及结果，新增事实回填原 ID。受影响检查、准确 PR 合并与阶段资源收尾完成后再进入下一项。
