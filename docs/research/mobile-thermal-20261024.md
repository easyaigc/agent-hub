# 手机发热排查与真机功耗对照（2026-10-24）

独立 iPhone 验收版的联网已恢复，准确安装的修复前／后产物分别完成真实持续回复和真实长历史滚动，四项原生 XCTest 均为 1 通过／0 失败／0 跳过。两场景 CPU 和会话写入下降，持续回复 CPU 功耗影响下降约 42.7%；长历史功耗影响只下降约 2.5%，热等级仍为 2，尚不能确认其发热显著改善。正式 App 和 Host 未部署；温度摄氏度、整机电池耗电和 Android 真机功耗仍未证实。完整脱敏结果见[逐项证据](../acceptance/mobile-evidence/mobile-thermal-20261024.json)。

持续回复均通过手机产品新建入口单次提交。同一 `gpt-6.1-sol`、`xhigh`、200 行输出，原 Electron owner 独立确认每条只有一次用户输入、一个完成轮且没有工具调用。修复前／后输出为 4646／4644 字符；窗口 38.53／47.33 秒，CPU 有效采样 30.88／40.79 秒。窗口包含发送、新建、模型等待和接收，不能用它推断客户端回复速度。

CPU 功耗数据的窗口覆盖均超过 98%。网络、显示并非各项都改善；各子系统数值、覆盖率和 trace 全程的蜂窝计数完整保留，不据此宣称网络能效优化。上述每个场景各一组配对，不能外推为长期或统计显著的电池收益。

采样为同一 iPhone 15 Pro Max／iOS 27.0.1，保持用户指定的外接电源现状，电量 100%、亮度值 0、低电量模式关闭，自然刷新率。系统在充电／满电状态之间自动切换。持续回复热等级前／后分别为 1→1／2→1；长历史为 2→2／2→2。初始热状态不同，不单独认定温升改善；等级不是摄氏度。Apple impact units 是同机相对指标，不是瓦特。逻辑写入包含会话主文件、历史与备份，不包含未读账本和测量日志，也不是物理闪存写入或电池损耗。

原因与修复：双端 EasyWork 原来每 100 ms 检查状态，空心跳仍读取完整历史，切换后旧订阅继续活动；已改为事件唤醒、稳定 epoch/cursor 不读历史、具名退订并保留重连修复。共享规则把失败和旧快照也计入 2 秒／10 秒补偿尝试预算；已验证且版本完整相同的保留正文不重复计算摘要，变化和 reset 仍校验。iOS 相同历史不重新发布／加密；真机 CPU 栈进一步确认未读账本解码、归一化与会话持久化开销。新增有界身份键缓存、路径与完整字节相同才命中的账本缓存及备份校验缓存；可替换实时快照按不滑动的两秒窗口保存，去除立即双写。命令意图先落盘、草稿保存、退后台 flush 与完整目标隔离保持。

Android 同步修复轮询、心跳、退订及保留正文摘要；额外定位到正文未变也重写全部加密历史分片。现在仅在内存提示未变且实际磁盘分片完整认证、目标与正文相同后复用原分片，仍更新运行时／新鲜度／游标头，缺失或变化发布完整新代。原生 Keystore 对照中，70 条相同消息的改写文件数 4→1，文件内容改写量 569,089→504 字节；13 项 API36 原生边界通过。此为合成原生存储收益，不代替物理 Android 的 CPU、发热和耗电测量；A6 继续暂停。

证据有效性：主程序和 Runner 的 UUID 分别核验。外部 Instruments 启动不会让 XCTest 安装候选，早先只有运行器更新的对照已标为无效，不纳入以上表格。最终每次先显式安装准确签名 App，保存主二进制 SHA-256／UUID、安装回执，核对安装 URL、trace 进程路径/PID和 xcresult 的同一物理设备。前／后两个场景分别使用同一对应二进制和相同测量代码，冻结源码与当前 iOS／共享核心逐文件一致。度量解析覆盖 XML 引用、缺失采样、时窗加权、错误 PID及不完整窗口反例，3 项通过。

联网预检 4 轮：实际 NWPath satisfied／Wi-Fi，未带认证的 Host 返回预期 401、互联网探测 200；认证后的真实历史与两条模型任务通过。原 -1009 保留；当前隔离 App／Runner 及仓库既有主程序 UUID 配置下恢复，不能把该旧失败唯一归因为单一因素。CoreDevice 本轮报告 wired 控制通道，不称为无线调试验收。

完整 `pnpm check`、最终 iOS 构建、双份真机 Release 测试构建和 Android 构建通过；持久化边界 11 项、未读跨进程替换／损坏边界及度量解析检查通过。早先 Node 版本、源指纹、网络、手势门槛、Instruments 附加／模板及采样结束后侧栏失败保留；一次 Windows Reader 在完整检查期间变化导致失败，独立复验和后续完整检查均通过。先前侧栏失败的那条模型输入原 owner 确认完成且唯一，没有重放；最终配对另用独立标记。

本任务独立 iOS App／Runner 与专用 Android AVD 已移除，原有安装保留；没有创建临时 Git 工作树、跨电脑 Agent 沟通或正式发布。私有原始 trace、xcresult、冻结源码和指纹位于 `.local/mobile-thermal-20261024/`。可复用命令见[开发指南](../development.md)；Power Profiler 指标定义见 [Apple 文档](https://developer.apple.com/documentation/xcode/measuring-your-app-s-power-use-with-power-profiler)。
