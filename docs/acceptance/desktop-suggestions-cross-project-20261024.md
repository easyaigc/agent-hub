## 原因与修复

原桌面已生成有效的预测请求、完成正文和 Trace。Host 的静态 `HOST_AGENT_ROOT` 指向另一项目，Trace 读取却以它校验准确原 owner 的其他项目 cwd，导致目录校验拒绝并返回空建议。

适配器现在从准确原 owner 的最新完成轮取得规范 cwd 及目录身份。Host 在读取前、中、后核对完整目标、来源轮次、路径和目录身份，再将该范围传入既有 Trace 链路。HTTP 不接受调用方传入目录；静态根目录、其他文件与命令权限、来源绑定、原生完成正文校验及六秒租期保持。
