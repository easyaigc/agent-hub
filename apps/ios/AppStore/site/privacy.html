Agent Hub 隐私政策

生效日期：2026 年 10 月 12 日 · 最后更新：2026 年 10 月 16 日

合肥博璀人工智能科技有限公司（以下简称“我们”）提供 Agent Hub iOS 应用。本政策说明使用应用及相关连接、通知服务时，哪些信息会被处理、用于什么目的，以及您如何管理这些信息。隐私与支持联系邮箱：admin@51easyai.com。

Agent Hub 是连接您选择的电脑与 Agent 服务的远程工作工具。任务在目标电脑上执行；您发送的文字、图片和文件可能进一步由该电脑配置的 AI 服务处理。请只连接您拥有或获得授权使用的电脑，并在发送前确认目标及模型服务。

1. 我们处理的信息及用途

信息 处理方式和用途
连接与配对信息 您添加的电脑名称、服务地址、Host 标识、项目与对话标识、设备公钥、配对密钥或登录凭据，用于识别目标、建立授权连接和恢复会话。使用 EasyAI 登录连接时，登录服务还会处理您的账号标识、登录状态及连接授权。凭据保存在设备的系统钥匙串中；应用不会要求您提交电脑的 Apple 账号或 Codex 账号密码。
消息与任务内容 您输入的消息、草稿、模型回复、工具执行信息、审批回答和操作回执，用于展示对话、提交您选择的任务、同步状态及处理结果不确定的操作。已发送内容会进入目标电脑及其配置的 Agent／模型服务。
图片与文件 仅处理您通过系统选择器选择、拍摄或明确上传的附件，以及您请求下载的文件。内容发送至所选电脑或相应服务，用于任务、文件传输和预览；不会自动上传整个相册或文件目录。
语音输入 您可在设置中选择默认电脑端或本地（手机）转写。电脑端不可用时自动使用手机系统听写。本地模式使用 Apple Speech，支持时在设备处理，部分系统或语言可能需要 Apple 的在线识别服务，音频不发送至所选电脑。使用电脑端且允许共享后，结束录音会将原文件发送至您选择的电脑，使用该电脑当前 Codex / ChatGPT 登录调用 OpenAI 转写服务，文字返回可编辑草稿，由您确认后发送。原录音暂存在设备和电脑，用于传输与查询原操作；未提交的设备录音在取消时删除；已准备的原录音在成功回填后删除，未完成副本在 24 小时到期后于访问时清理。电脑的临时音频与转写文字在 24 小时到期后清理，保留防止重复提交的操作记录。OpenAI 对已收到音频的处理受其服务条款和隐私政策约束。
通知与设备信息 启用通知后处理应用生成的设备标识、APNs 推送令牌、目标电脑／会话标识、订阅偏好、事件及投递回执，以发送提醒、撤销订阅和恢复通知状态。已实现的加密通知通道向中继传输加密摘要；中继仍可处理路由标识、推送令牌、时间及投递状态。
本地状态与诊断 在设备保存设置、草稿、最近读取的对话缓存、未读状态、待确认操作和下载文件，以支持使用与恢复。连接或通知服务可能处理必要的错误及运行日志。访问我们的网页或服务时，服务器可能记录 IP 地址、访问时间、请求路径和浏览器信息，用于安全与故障排查。

可选项目任务服务：另行配置的 Task Hub 主服务处理成员标识、设备会话、项目权限、任务、反馈、产物、验收材料和操作回执。主服务的运营者管理成员账号、数据保留与删除；局域网直接连接 Agent 不要求 Task Hub 账号。

2. 系统权限

相机用于扫描配对二维码；麦克风用于录音；语音识别权限用于手机系统听写；本地网络用于发现和连接您选择的电脑；通知用于任务提醒。我们在相关功能需要时申请权限。您可以在 iOS 设置中撤回权限，受影响的功能将停止或无法使用，其他不依赖该权限的功能仍可使用。图片和文件选择由系统选择器控制。

3. 信息接收方与第三方服务

首次向真实电脑及其模型提交任务、附件或继续执行操作前，应用会显示目标电脑、Agent 和模型，并请求明确的数据共享许可。您可以拒绝；草稿不会因此发送。允许后需再次主动提交，不会自动重放输入。许可保存在本机，可在设置中的“AI 数据共享”撤销；许可范围以界面披露为准；选择跟随电脑配置表示允许该机器目标当前及之后调整的 AI 配置，请在电脑端核对实际服务商和处理政策。切换 Agent 或机器运行目标后需要重新确认。本地界面示例无需此许可，因为它不发送内容。

  • 您选择的电脑和 Agent 服务：接收您提交的任务及附件，并按其配置处理内容。Codex 使用的服务可能包括 OpenAI；EasyWork 及其他连接使用您实际配置的模型或服务提供方。模型提供方的数据保留、训练使用及所在地区由其政策和您的账号设置决定。
  • Apple：提供系统权限、文件与照片选择以及 APNs 推送。相关处理亦受 Apple 隐私政策约束。
  • 通知与连接基础设施：您启用相应服务时，部署该服务的运营者及其基础设施供应商会处理提供服务所需的连接、订阅和投递数据。直接连接电脑的任务内容不会仅因使用本应用而自动上传到我们的业务服务器；使用其他中继或模型服务时，以所选连接的实际配置为准。
  • 您主动发起的支持请求：邮件系统会处理您的联系邮箱及您发送的说明和附件。请勿在支持邮件中提供密码、完整访问密钥或无关的私人对话。

我们不出售您的个人信息，也不使用应用数据进行跨应用广告追踪。应用未集成用于广告追踪的 SDK。为遵守适用法律、有效的法律程序或保护服务安全，我们可能在必要范围内披露依法应提供的信息。

4. 保存与删除

本地设置、草稿、缓存和下载文件会保留以支持使用及恢复。移除客户端会停止该连接，但不等于删除电脑上的对话，也不保证立即清除所有历史缓存。删除应用可移除其应用容器内的数据；您另行导出的文件、系统备份和可能由 iOS 保留的钥匙串项目需要分别管理。撤销电脑端密钥可以使旧凭据失效。

已发送到电脑、模型或其他服务的内容按接收方的配置和政策保留，须在相应服务中删除。通知中继的已结束投递记录按过期时间清理，当前实现通常在过期后七天清理；订阅、设备绑定及必要的撤销状态可保留更长时间以维护投递和防止旧请求恢复订阅。关闭通知或移除客户端会发起订阅撤销，网络不可用时可能需要恢复连接后完成。

我们控制的服务仅在提供服务、安全排查及适用法律要求所需期间保留信息。您可以通过下方邮箱请求核查或删除我们控制的数据；我们可能需要验证您的身份，并说明法律要求、他人权益或技术边界导致的保留情况。

5. 安全与数据传输

我们使用系统钥匙串保存凭据，并为适用的缓存、通知摘要及迁移文件提供加密保护。连接安全取决于您选择的地址和传输方式；请优先使用可信的 HTTPS 或已配对的安全连接。局域网 HTTP、导出的文件、您自行部署的服务及目标电脑仍需由您妥善保护。通知元数据与所有任务传输并非都属于同一条端到端加密通道。

数据可能在您所在地区、目标电脑所在地、Apple 或实际模型／中继服务部署地区处理。发送前请确认所选服务及其数据处理政策；本应用无法替第三方承诺固定的数据存储地区或保留期限。

6. 您的选择与权利

撤销 AI 数据共享许可会阻止后续提交，已送达电脑或第三方的内容不会自动删除，正在执行的任务也不会自动停止。请在对应电脑／服务中停止任务或提出删除请求。使用“跟随电脑端配置”时，许可覆盖该配置所使用的服务，请在电脑端核对实际提供方；应用无法读取或承诺所有第三方提供方的策略。

您可以修改或移除连接、关闭通知、撤回系统权限、编辑未发送草稿，并在目标电脑或第三方服务中管理已发送内容。根据适用法律，您可以请求访问、更正、删除个人信息、撤回同意或就处理方式提出异议。联系我们时请说明涉及的服务及请求范围；不要发送完整密钥。撤回授权不影响撤回前已依法进行的处理。

7. 儿童与政策更新

Agent Hub 面向需要管理电脑任务的用户，不以儿童为目标受众，也不主动要求提供儿童个人信息。如监护人认为儿童信息被不当处理，请联系我们。功能、接收方或处理方式发生变化时，我们会更新本政策及日期，并在需要时提供提示或重新取得授权。
