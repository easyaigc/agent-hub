# Trace 存储修复：范围与验收

本次交付仅覆盖正常运行停用全量诊断、缓存计量、历史回收及其原生采集兼容，当前功能状态只维护于[唯一清单](../plans/android-ios-alignment-20261107/progress.md)。手机建议全文、采用、追加／替换与撤销代码保持主线，既有 iOS 用户真机确认和 Android 主线基线保留。

## 根因与修复

正常启动曾向原执行器继承 `CODEX_ROLLOUT_TRACE_ROOT`，每轮重复保存完整上下文和工具负载；下游清理速度无法约束活动 writer。现在仅在原生建议已经配置的 macOS 入口移除该诊断开关，保持原参数、其余环境与转发字节。原生建议仍被动读取原桌面已发起的请求、返回和原安全判定，不新增预测请求。仅旧 Trace 安装保持原路径；Windows 不声明本机未验证的新 producer 能力。

历史回收原先只识别末条 rollout 结束；Schema 2 在其后另写 recording completed，因而被永久误判为未封口。修复分别核对业务结束、writer 结束、连续序号、时间与稳定对象；尾随活动、未知格式、无证明及占用文件继续保护。每聊天最新精简结果须持久化并读回，才能按原安全条件回收已替代原始内容。

存储 worker 独立于建议观察开关，在原 retention opt-in 下有界扫描、计量、退避及恢复。超过二万目录仍能推进，未完整扫描的字节统计明确为建议性下界。512 MiB／1 GiB 仅为压力阈值，不能冒称对旧活动 writer 强制限额；正常模式不再增长依赖实际执行器已停止全量记录。

采集兼容包含已知 Electron utility 父链、原安全日志来源、新结果可选评分字段和旧占用／挂载身份恢复。恢复仍核准确进程实例退出、私有目录、原对象及最终命名空间，未知和活动 writer 不删除。Host 独立升级只接受明确消费模块差异；原生采集、安全、脚本和 helper 的全部关键字节必须与当前 producer 相同。

## 交付范围

本次没有纳入排查期间另做的 Host 连接／执行适配、完整历史投影、新建首发确认、原生队列调度、打开聊天策略或 `threadSource` 创建参数变化。最新主线相应文件保持原字节。只读进程身份核对与默认不生效的可选写前回调作为兼容支撑保留，不新增业务命令。

因此，无需为纯存储修复重复整套手机采用／撤销流程；需要核对的是已有结果读回、来源／安全约束和持久化完整性没有被清理破坏。此前测试聊天没有自然建议结果的事实保留，不将其写成已验手机通过，也不将它作为未修改手机业务的新增完成门槛。

## 证据与收尾

原始日志、准确输入摘要、实际 producer 指纹、操作回执与最小脱敏证明保存在本机受保护的任务目录，不提交真实聊天、附件、机器路径或凭据。此前广候选独立保存，未验证的业务扩展不混入本交付。任务独占编译／测试资源在阶段结束后回收，最终核对远端 main 实际包含交付，不以本地提交或推送分支成功替代主线合入。
