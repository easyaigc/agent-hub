# 暂停状态同步修复（2026-10-24）

关联 F18（事件恢复）、F20（工具终态）、F39（停止／恢复按钮）。

## 根因与范围

原桌面实时只读快照已是 idle／interrupted，末轮工具仍可保留 inProgress。正式 Host 的事件与最新历史却都返回 running／inProgress。独立原 owner 读取确认当前完整快照修订号为 2；Adapter 原来的低修订接纳条件只覆盖新输入／新轮，遗漏同一输入、同一轮的终态重建，导致刷新仍拒绝新快照。

共享 Adapter 只接受准确原 owner、完整 Thread/Host 身份、相同非空输入和末轮 ID、旧末轮 inProgress、新末轮明确终态及 idle/systemError 且无活动轮的重置。终态按输入／轮次保留有界栅栏，旧运行快照与已知旧修订链丢弃；正常新输入／新轮不受阻。工具展示继续由整轮终态收敛，不改写上游记录，不提交或重放模型输入。未知、缺少身份、不同输入／末轮或仍有活动轮不能凭低修订宣布停止。
