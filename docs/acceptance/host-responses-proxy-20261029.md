# Host 可选模型代理验收（2026-10-29）

本轮范围为 Host 专用推理 API、本机显式开启、Demo 后台配置及 ai/chat 网页真实调用。移动原生、Windows 与 A6 暂停范围未新增验收。

## 实现与部署

- 默认关闭；配置准备器生成的开关仍为 `0`，仅人类明确要求后设置 `HOST_RESPONSES_PROXY_ENABLED=1`。默认独立端口 `8797`，避免设备发现端口冲突。
- 固定 Codex 内部 Responses 上游；独立代理 Key、TLS、模型允许清单和元数据回执。Chat 结束标记在上游完整验证后发送，未知操作不重放。
- 独立冻结现场使用锁定依赖，七组件从空 dist 顺序编译；统一包 SHA-256：`d98731c87708600cde5d1c02994e25c5fcbe62c102063114e420207e1a593d33`。本机实际 ESM 依赖指纹匹配，Host ID／原 Host Key 保持。
- Demo 使用独立平台和模型绑定，代理 Key 仅留后台；访问规则限定本次管理员。只读挂载专用证书，以 `NODE_EXTRA_CA_CERTS` 信任，未关闭 TLS 校验。

## 保留的失败与限制

早期产品候选的一次页面回复正确，但流式收尾回执为 unknown；该原回执保持，未重发原输入。修复后使用新输入及新回执通过。中途页面请求还遇到 Demo Redis 连接重试耗尽，尚未进入模型；仅重启后台恢复连接，原镜像以及 Web／Redis／数据库容器保持，恢复后独立验收通过。

主工作区的移动一致性生成检查被非本任务的 `apps/android/src/main/kotlin/com/agenthub/android/UsageViews.kt` 缺失／过期变更记录阻断；该文件与其记录未作修复。冻结验收现场的对应检查通过，不能用它掩盖主工作区此项阻塞。

上游为实测的 Codex 内部接口，版本升级需重验。原始 Responses 与 Chat 转换边界、未支持的持久会话和参数见运行／协议文档。完整密钥、地址、请求 ID、合成验收正文及机器证据保留在本机私有验收目录，不写入仓库。
