# P7 加密迁移与存储恢复档案

## P7-5b 加密封装与双向合成向量

本阶段只建立加密封装，F55整体仍开发中。Android使用既有Bouncy Castle的原始UTF-8 PBKDF2-HMAC-SHA256（210000轮、32字节），16字节盐、12字节nonce、128位AES-GCM标签和iOS同一AAD；新随机盐与nonce，不正规化密码，保留NUL。密码按ICU字素计数至少12，已覆盖组合重音/连接emoji，未宣称所有系统Unicode版本一致。文件边界包含base64与JSON膨胀；大文件堆内存/配额上限另待验。

使用未改动的iOS `EncryptedMigration.swift` 非iOS部分和合成L10n shim编译macOS Swift工具，生成五组纯合成字节、Unicode/NUL密码和派生密钥。API26、API37和新手机API33各6项辅助通过：原Swift封装读取、派生字节、Android回环、错密码/盐/nonce/密文/标签/AAD拒绝、严格字段/版本/重复键/UTF-8/base64/长度校验、随机性与空二进制。每环境输出5个Android封装，由原Swift源码独立解密核对，共15个双向样例。18份逐方法字节证明核对自有验收包原no_backup加密文件和相机私有输出不变。无会话、Host、真实凭据或业务附件参与；0模型输入，累计220/P4205。

原API37准备第一次被私有APK归档并发写入保护拒绝，未安装/执行。保留原失败，归档改为写完临时文件、读回校验、原子硬链接发布后重试通过，源/包未变化。当前原生编译与一致性检查分别保存；原G根检查复用按1007份匹配、6份已在G/H/5a核对的变化与新增源逐项登记，不宣称本阶段重新跑完整根检查。

**未关闭**：Android本端资料Schema/来源/附件与不可变回执、无真实电脑的新安装限制、原子导入/回滚、设置入口/系统导出导入；加密格式互通不等于可导入iOS SavedSession。Android完整UI/IME/AX/主题/横屏、真实Key/I/O/配额及原环境待验继续。iOS源码未改、未跑原生App，A6仍暂停；业务任务/项目暂缓。

精确源码/包/runner、向量工具/原iOS源、逐环境结果和负向记录见[P7-5b审查数据](../P7-migration-crypto-review.json)与[验收证据](../../../acceptance/mobile-evidence/android-alignment-P7.json#android-migration-crypto)。私有原始日志、导出封装与恢复包留在工作树外，公开记录不含机器绝对路径或真实资料。

## P7-5c 迁移候选资料与原ID冷读

新增内部候选资料层，只向独立Keystore子目录的一份AtomicFile发布已校验候选，不改变当前安装、配置或原业务记录。当前格式绑定目的App真实包ID，限制8MiB明文/12MiB封装；原始记录文本保持原样。检查外层版本/来源/UTF-8/重复字段/深度，附件UUID、原清单/base64/大小/SHA，调用同一原日志解码器核对不可变操作ID、意图SHA、目标与返回，并核对原提交快照的文字/设置。嵌入结果字符串另做严格JSON解析，保留重复Host字段反例。原回执的unknown/submissionAttempted不改写，不创建命令执行链路。

稳定候选ID与完整明文摘要共同形成原结果。相同ID/摘要只读取原密文结果；同ID换内容、旧请求替换新候选、未提供准确原候选或并发初次覆盖均拒绝。并发初次暂存只产生一个候选；旧候选密文校验失败时拒绝覆盖、保留原坏密文，测试只修复自有样例后读取。候选暂存的原子发布不能替代多记录安装激活/回滚。

最终同一产品包/runner：API26、API37各15项候选/加密，新手机按3+3+3候选与6加密分组；三环境各7项原回执/存储fixture回归，并分别独立执行seed、停止准确自有包进程、PID消失核对、全新进程原候选读取。共72个有效执行方法、3组实际进程冷读；45份逐方法原加密文件保护（候选27份no_backup、加密18份no_backup与相机输出）及6个冷读保护断言通过。各环境5个Android封装又由原Swift加密源码独立读取。边界回归可写自有HTTP fixture，不等于真实Host写入；本阶段0真实模型输入，累计220/P4205。无产品UI变化，未取得迁移页面通过。

负向记录保留：较早两SDK中间候选通过不计入最终总数；较早手机15项合批在480秒上限超时，按失败保留源/包/runner与回执，不将部分方法或后续小组升级为原合批通过。最终手机分组有各自指纹/回执。测试包从已经核对的工作树外归档读取，避免并行完整工作区构建覆盖安装候选。当前完整`pnpm check`命令退出0，1014份登记输入与18份根配置无漂移；文档结果更新后另核格式/一致性。
