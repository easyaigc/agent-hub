# EasyWork 原操作等待与父子运行恢复

当前开发、验收、交付和剩余范围只维护于 [唯一台账](../plans/ios-easywork-alignment-20261112/status.json) 的 `F44-bounded-offline-wait-and-unknown-ack` 与 `F18-event-reset-child-recovery`。本页说明方法和证据范围，不维护另一份完成数。

本次使用原模拟器、原已配对目标及正常 App 唯一的 Store，向同一既有聊天只发送一条新的合成输入，产生一个父 Run 和一个子 Run。子任务唯一成功终端命令为 `sleep 45`。观察器先验证真实加密回复，再仅阻断本机交付，其他通道在该测试进程内受控不可用；不宣称系统实际断网。原请求等待结束实测 32.2745 秒，本地结束等待实测 26.22 毫秒，新草稿仍可编辑和持久化。观察到子任务运行后关闭原传输；子任务在冷启动前已完成，不能报告冷启动时仍在运行。

冷进程只查询同一原操作，禁止新的 `turn/start`。同一真实父聊天读取被延后，在另一聊天完成读取后才释放，原结果不能替换当前聊天、正文或草稿；返回原聊天后核对父子权威终态，并恢复测试前的原稿值。EasyWork 正文按内容段投影为 `messageId:partIndex`，该单文本输入核对准确 `:0`、正文及唯一性。普通模拟器界面和真实桌面均核对最终回复与子任务成功；原稿恢复由 Native 逐值断言证明，空输入框截图只证明当前可见状态。

发送阶段和修复后的冷恢复阶段分别为真实 Native 1 通过、0 失败、0 跳过。原始前置摘要、目录重建、只读允许集遗漏和 wire／投影 ID 混淆造成的失败全部保留，不能把失败改签通过。测试前额外密封意图观察器因缺少 `EASYWORK_HOSTED_NATIVE_REPLY_PREFLIGHT_CASE=<case UUID>` 未启用，未生成的补充见证不列为通过；生产路径在传输前持久化原 outbox/recovery 的既有实现与已合交付范围单独复核，不补造文件或重发原输入。

重复、乱序、缺口及 branch/reset 的既有 I2.5／I2.7 主线交付按原限定断言与相关调用链复核复用；本次补的是在途父子任务、未知 ACK、结束等待、新草稿和冷恢复。历史、当前实际运行和匹配复用分别引用唯一台账，不将其扩大为所有版本、通道、整个父功能或 Android 通过。桌面具名查询和权威快照契约已存在，本次不新增任意 IPC 或业务代理。

具名 Native 使用独立验收 bundle、XCTest、模拟器、`-ui-testing -restore-testing -hosted-original-store-acceptance` 以及匹配的 case／normal-store 环境声明；原客户端、绑定和固定证书必须相符。需要额外传输前观察时同时提供上述 preflight case 声明。所有配置和原稿备份只存私有文件；未知结果只查询原 ID。普通、设备、Release 与 R2 不进入此存储开关。新调用使用官方 `-collect-test-diagnostics never` 保留结果及 XCTest 附件，避免无关系统诊断；不修改共享设置。

七张原业务表的旧行、原上传日志、共享组身份资料、普通文件、旧绑定和桌面未提交草稿分别核对保护。恢复与证据复核完成后回收展开 App、SDK 支持、测试 bundle、编译缓存和测试专属密封备份；正式实例、原模拟器、合法绑定、原始结果和必要交付／回滚材料分别保留。
