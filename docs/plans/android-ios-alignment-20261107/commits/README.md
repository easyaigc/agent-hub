## 口径和维护

- 所有直接iOS记录保存完整SHA、父提交、日期、标题、实际首父差异路径和patch摘要；功能概述来自差异，标题仅作定位。合并记录解释净集成范围，不把一个功能多次计数。
- 合并来源的相同文件/补丁可复用审阅；冲突净取舍独立记录，例如IOS-323原回执的operation/message/thread校验与未知状态。没有以全部合并完全patch等价作为已完成声明。
- 早期单图折叠、固定20MiB传输门槛、旧语音失败弹窗、初版可视化联网策略等保留历史行；当前策略按最新功能清单。旧档案的Android未实现/已通过状态不直接带入。
- `git rev-list --full-history <head> -- apps/ios`覆盖350条；对全部可达提交按首父/root实际差异筛得332条，两个集合的差集18条单列。共享候选限旧审计头之后的Host/Adapter/Protocol/Relay/mobile-core，不声称全仓1292个提交都是iOS功能变更。
- [机器账本](../commits.json)保留完整路径和来源映射；[旧217条审计](../../android-alignment-20261022/commits.json)保持归档，不作为当前唯一清单。
- 后续冻结新main时新增节点，逐条补功能去向/替代关系与影响的AC，不删除旧记录；新代码没有证据时保持待验。
