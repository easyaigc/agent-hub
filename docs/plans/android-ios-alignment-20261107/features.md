# 完整功能、交互与界面清单

基线和范围见[计划](plan.md)。此表保留现行 75 个功能 ID，逐条列出共同断言、关键交互、界面和交付去向。70 个活动产品项不代表 70 项都未开发；“已实现”与“已按当前整包验收”分别判断。本轮未执行产品验收，不能把此清单视作新通过证明。

来源快照和全部 iOS/Android 关联路径见 [features.json](features.json)，原编号来自[产品 manifest](../../product/mobile-parity.manifest.json)；提交来源见[提交索引](commits/README.md)。每条均对应 `AC-Fxx` 验收行，共用门槛见[验收方案](acceptance.md)。未来新增子功能先保留所属 F 的稳定 ID；超出现有共同断言的新增功能需另行登记，不能挤入旧通过范围。

2026-11-07用户补充：[每项双端/双Provider规则](three-way.md)与[75项四格范围](provider-matrix.md)贯穿全部功能；当前C1-RID原回执守卫的实现/辅助/原生编译和未完成在线验收分别见[进度](progress.md)。原表断言和历史通过不因此批量升级。

## 读表规则

功能断言采用冻结主线原文；“交互补项”是必须验收的操作/状态；“界面补项”是对应页面的完整性要求。目录选择、已有项目导航及对话分支属于本轮范围，Task Hub 业务和项目 Git 处于暂停。F74 为 Host 依赖检查，不增加手机模型代理入口。

## 在实现中逐项核对的新增细节

- 迁移导出文件名按独立导出生成；iOS 当前使用 UUID 后缀，Android 现行入口仍为固定默认名。N1.3 统一产品语义并验取消/重复保存，不用文件名代替内容或操作身份。
- 原录音只读列表、每次保存重新核对大小/摘要、首次载入和导入后刷新、系统取消保持原件，列入 N1.3；不授予继续录音或重试原转写的权限。
- EasyWork 和通知安装授权策略字段纳入版本兼容矩阵。迁移记录不恢复旧安装身份或旧设备授权；明确核对当前 grant/绑定和通知关闭策略。
- 菜单、资源预览及分享覆盖对阅读可见性的影响，与资源原始 owner/不可变副本共同验收；Android 已有部分 owner/可见性门禁，先核生产调用链，不据方法名断言缺失。
- 下一轮模型/强度/速度预览与电脑真实默认权限分别显示；额度圆环/余额及侧栏入口按最新 iOS 排布，不能只复用早期截图。

上述是当前值得优先复验的细节，完整范围仍以每条 F、提交账本和验收行合取，不能只实现这五条。
