## 实现与 iOS 对照

P7 候选 `77c7051c` 将原迁移租约的创建/发布权限，与新 Session 的正常运行权限明确分开。原 storage、Session、lease、operation 和确认发布的 generation 共同约束一次性交接；Controller 确认原 raw writer 释放后，Activity 与冷夹具使用同一恢复函数，准备全部十个子存储、恢复 Session、核对指针再提交。取消、失败、未发布、新请求和旧 Session/child 不能借目录存在继续取得权限。

既有迁移只读入口接收已存在的原始目录，核验后再将受限 Context 交给 codec；缺失基目录不得由 getter 创建。原 candidate 固定按原 generation 与 receipt 读取，保留完整 frame、封闭图和摘要校验。严格读取统一使用 no-follow、非阻塞打开及实际 FD 身份检查；未知关闭保留原句柄、原线程与异常。主统筹另修正所选文本的格式探测、pointer/子目录读取中遗漏的 FD 生命周期。

激活后和第三进程都逐项比较最初 writer 的全部 destination 路径/密文 SHA，不把激活后的 snapshot 当成原件基线。新 Session 的合法后续编辑允许改变新代内容；原 source、candidate、旧 destination、未知操作和迟到草稿仍独立保护，不恢复 URI 权限、回调、队列或旧业务操作。

阅读线 `72a98867` 只新增一个实际 Store 组件场景：写入已进入真实加密存储锁的队列后，切后台再回前台，旧可见性租约不得清除未读；新的正文阅读仍保留独立未读问题，迟到通知不得复活已读正文。没有确认新的生产阅读缺陷，未增加第二份账本或消费流。

iOS 的迁移/原件保护、实际最新内容可见才已读、正文和问题阅读分离等共同断言保留。Android 本轮没有新增页面、token 或文案；源码对照不等于 iOS 事务时点等价或新 iOS 真机通过。功能、交互与 UI 的真实验收继续分别登记。
