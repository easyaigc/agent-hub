# 桌面旧快照阻断手机同步（2026-10-18）

## 真实现场

用户报告同一对话电脑已经完成，手机持续停在旧正文及执行状态。对既有正式 Host、原生 iPhone 16 的原连接及准确原 owner 分别只读核对：手机与 HTTP 历史均停在旧轮次；原生持久记录已存在后续完成回复和新输入。持久记录仅用于对照，不能据此恢复运行时可控资格。

独立 IPC 监听同时收到同一 owner、同一 Thread 的两组完整快照：旧历史修订号较大，新历史修订号较小，后者包含准确旧末轮的结束、新轮及当前输入标识。旧 Adapter 无条件忽略较小修订，后续新流增量也无法落到正确基线。反复 following 仍会先后收到两组；更频繁轮询不能修复。完整历史工具在此 legacy 来源返回 `thread/items/list is not supported yet`，这不是聊天不存在或手机网络断开的证据。

## 已实现

完整快照仍先校验私有 socket、协议版本、当前 owner、Host 与 Thread。只在准确旧末轮已在新快照中结束，且后面存在新末轮、新输入标识不同的情况下，允许切换修订基线；不按时间或正文推断。新快照允许省略已分页裁剪的更早前缀。

将旧输入／末轮标识和已知旧修订链保留为退出流，迟到的旧完整快照和旧链增量不会撤回新历史。普通旧修订仍忽略；没有连续性证据、未知增量缺口及其他 sourceClientId 的内容不能取得控制权。真正的 owner 变更与断开重新建立边界。没有放宽缺口校验、启动执行器或修改官方记录。

## 验证范围

新增真实 Socket 回归覆盖：较小修订的新历史、迟到高修订旧快照与旧增量、当前流完成更新、重复 following、无连续性证据、未验证客户端、普通递增、真实缺口撤销资格及 owner 交接。旧实现未能接纳新历史，修复后同一专项通过，执行命令为零。

正式 Host 与手机真实更新按本次实际部署指纹另记。只复测新增同步恢复，不重复既有采用／撤销套件；保留原连接、草稿及未知操作。手机无需新协议字段，当前普通安装版本可使用该 Host 修复。其他电脑及 Windows 不由本机证据推定。
