# 阶段115 最后 writer 原关闭回执

基准为已合入 PR160 的主线 `1ac47fbb`。录音 worker 的 `ended` 只反映任务完成，原 writer 在 finally 关闭。迁移 quiesce 检查 ended/join 后，仍需 Gate 确认本机写入者已释放。此前两个 writer 工厂的最后关闭路径均先移除 token/State，实际关闭失败后会丢失这一阻挡。

Frozen 和最后 writer 复用一次关闭状态。非最后 writer 只释放自己的 token。最后 writer 在实际关闭成功后才移除 token 和原 State；失败保留同一异常与句柄，重复关闭和 requireCurrent 观察原失败。普通与F59两个工厂均在新 record 注册前拒绝已尝试关闭的 State。混合 writer 始终关闭首次打开的 State.handle。

原六项 Frozen、真实 FileChannel、writer 与并发用例保持。新增四项覆盖非最后 writer 不关闭句柄、普通 first/F59 last 的失败、普通 last 的失败及并发新 writer、严格 F59 first/普通 last 的实际成功关闭与旧 token 隔离。失败注入覆盖普通 Handle，严格三资源端口本轮只验成功关闭。
