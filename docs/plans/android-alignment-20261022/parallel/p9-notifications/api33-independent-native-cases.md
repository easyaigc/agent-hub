UI helper verification covers selected default records, not a complete default-family or key baseline. Sound tests deliberately leave pending/corrupt private records and have no @After cleanup. Root must retain minimal proof and verify exact ownership before deleting only those test-generated namespaces.

The real post fixture injects a reading port returning constant7. Badge=7 proves a notification field, not P7 unread/lifecycle acceptance. `mayPresent=false` is an AtomicBoolean port check. Channels are system-owned; their reference-policy comparison does not prove lockscreen UI. URI reads do not prove system UID grants or audibility. Codec tests do not play audio. Warm malformed/unknown-ticket Activity tests do not prove valid/cold SystemUI routing. iOS files are source counterparts only; no iOS/A6 result is added.

The source pins match the existing Root compiled-source map; APK/signer values are copied from its recorded attestation, not rehashed or installed here. Current reading/IO evidence cannot be relabelled into this collector protocol or notification consumer proof.
