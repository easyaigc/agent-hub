# 输入框聚焦与长按语音（2026-11-16）

F64，UI06／UI21，S04／S18。主输入区按当前聚焦状态分配长按手势：未聚焦时长按 0.5 秒启动语音；已聚焦时禁用父层语音手势，保留系统粘贴、选择与光标操作。短按继续文字编辑，显式麦克风及无障碍语音入口保持。录音取消、原草稿、转写目标隔离与显式发送沿用原实现。

实现位于 `apps/ios/Sources/RootView.swift`：高优先级长按使用 `composerFocused ? .subviews : .all` 的手势范围；已聚焦时空框改用既有“发送消息”文案，并去掉长按语音无障碍提示。不是只在回调中判断焦点，系统子视图手势仍可接收长按。普通和灰字建议输入共用此边界，Host、协议与 Android 实现不变。
