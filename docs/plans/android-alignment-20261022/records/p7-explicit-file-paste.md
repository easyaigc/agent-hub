# P7 显式文件粘贴档案

## P7-1a 原草稿本地准备

对照iOS外部附件/粘贴源码，Android附件菜单增加“粘贴图片或文件”及来源说明。只有显式点击才读取系统剪贴板，快照有序content URI，不将普通文本/网页/file URL或URL对象转为附件。后台有界读取真实Provider名称、类型与字节，空/20MiB以上/不可读取准确报错；声明/实际长度不一致拒绝。固定应用错误经类型选择翻译，Provider诊断保留cause，不整串翻译。原附件准备、共享容量/代次规则、加密存储和既有发送链路沿用，粘贴不上传/发送。

加号菜单捕获原草稿目标，目标/选择变化关闭旧菜单，选择文件和粘贴旧回调均先核原目标。5个新原生方法覆盖快照拒绝/上限/原顺序、真实FileProvider文本/图片字节与名称、空/超限/不存在、系统剪贴板本地添加和目标切换。另9附件归属、4操作触达、1完整catalog回归，三平台各19项；API26双倍字号/API37深色各5，共67辅助。早期30项保留旧runner指纹，不提升为最终结果。新测试引用私有扩展被编译器拒绝，改Native Uri解析器，仅验收器变化。

3个实际原目标/资源整例通过；真机/API37显式系统粘贴得到相同107字节与文件名，原草稿文本/目标、默认存储保持，观察到新文件ID已写入本机元数据。仅验收器移除新增本地文件后恢复原附件列表，并恢复原系统剪贴板；API26此前为空且无法精确清空恢复，未写入，单列待验。控制激活是原生语义，非坐标触摸；来源是同App受控FileProvider，不是独立外部App。模型此前仅引用验收器文件，未读该资源，本阶段无新模型输入/上传/提交。累计219/P4 205不变。70份默认存储证明，实际HTTP/包/源码摘要见证据。
