# P7 拍照与本地准备档案

## P7-3a 原请求与私有输出

对照iOS“拍照”/UIImagePicker：Android在当前过渡附件菜单增加同名入口，原菜单释放、主窗口焦点及一帧后才进入权限或系统相机。捕获准确草稿目标、附件导入代次及原错误代次；权限结果、取消、旧回调和迟到失败只处理原请求，不能消费新请求、删除新输出或覆盖新错误。新相机、图片选择与已有文件选择期间禁用加号，旧文件/粘贴菜单动作也重查入口空闲，避免同时打开多个系统输入。

系统相机使用平台Capture合约和明确的图片捕获intent查询；只创建本次UUID命名的私有cache输出。EXTRA_OUTPUT和单项ClipData指向同一FileProvider URI，只授予该URI读写权限，不信任结果携带的其他URI。回调沿用照片JPEG/EXIF归一化、有界读取及原草稿加密保存；完成后撤销授权并清理本次文件，取消/拒绝/不可用/坏图片也保留原稿，旧请求不触碰新文件。只准备本地内容，没有上传、发送或模型轮。外部相机写入期间为App私有临时明文，回调后才进入加密草稿；进程死亡时原请求、结果与孤立临时文件恢复仍是未关闭项，不宣称全部系统生命周期已完成。

原iOS权限和相机视图与Android外部系统Activity是明确的平台差异；名称、原稿、取消、本地准备及显式发送断言共同维护。Android仍是过渡菜单，iOS分组/图标、最近30图横向快选与完整附件面板在下一批补齐。新增一个Android权限拒绝文案，1603共享+77平台共1680双语键。
