Each PixelCopy image comes from the owned dialog's actual Window and is cropped to
the measured sheet bounds. Records include Activity and dialog geometry, actual
display rotation, OS/rendered font scale, app theme callback and TextLayout colors.
The controlled short dialog is not a physical short display, and synthetic font2
is not OS font2. The landscape lane verifies its current environment; it does not
rotate the display or prove restoration across rotation. Semantic IME Done plus
an observed hide is not a physical keyboard-button hit. Native AX node assertions
do not establish TalkBack or VoiceOver speech/traversal.

Every case uses a fresh private session/storage alias and synthetic inert target,
credential bytes and uncertain journal. The selected client stays Demo; original
draft, six target values, identity, credential/journal bytes and permission states
must remain unchanged. Default `mobile-v1` families, including atomic siblings,
retain the existing64-root/1024-file/262144-byte bounds. There is no cap increase or
trimming. Pairing buttons remain empty/disabled; the safe-touch allowlist excludes
submission, scan, permission, discovery-row activation and model actions. This is
presentation preparation, not a connection or network pass.
