## 4. 边界检查必须覆盖的输入

公共核心和协议使用同一份脱敏固定向量，至少覆盖：

- null／缺字段／未知枚举、时间／数字精度、二进制 Base64、Unicode、UTF-8 字节长度与内容 SHA-256。`ReadingIdentity` 等键按既有字节向量验证，不依赖各语言 JSON 默认编码“碰巧相同”。
- 同名项目、同 thread 字符串但不同完整目标，账号／工作区切换和连接配置代次改变。
- 同操作 ID 相同／不同正文或附件；提交前保存失败；请求已写出但确认未到；只能查询的不确定状态。
- 旧事件、重复／乱序、epoch 改变、窗口过期和旧页面取消；业务 ID、事件位置及加密序号不能相互替代。
- 首条上传中断、结束等待、Host 无该操作、旧确认晚到和后续独立新草稿。
- 过期 Run／审批／计划版本、只读路径、缺失能力、错误凭据／证书／绑定、通知撤销旧代次。
- 通知密文／AAD／目标不一致、损坏迁移文件与有限额附件／音频，Node／Swift／Android 加解密互通。

仅为关键行为与边界写测试，不增加重复静态类型或镜像实现的无效测试。所需编排脚本在对应阶段建立，当前现有脚本不会自动执行 Android 场景。
