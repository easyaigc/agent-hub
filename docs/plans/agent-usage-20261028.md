# Agent 额度与余额接入计划

日期：2026-10-28。功能 ID：F73。状态：**用户已确认修订 6 并要求实现；公共协议、Codex／EasyWork 接入及双端原生代码已落地，实际与辅助验收分列**。

## 目标与本轮交付

Host 返回所选 Agent 的余额和使用限制，覆盖算力点、credits、货币、token／请求配额，以及多个时间窗口；余额与限制可以同时存在。先定义公共契约，分别接入 Codex 和 EasyWork，再接入 iOS／Android。手机 UI 已确认并据此实施；本轮不替换正式服务、不改变既有连接身份、不联系其他电脑、不提交模型任务。

- [领域类型与约束草案](../design/agent-usage-contract.md)：判别联合、精确数量、来源、完整目标、缺失语义与适配规则。
- [手机 UI 设计](../design/agent-usage.md)：客户端选择与侧栏个人空间两处同时展示、详情、状态、交互和双端一致性。
- [可交互 UI 源稿](../../design/mobile/agent-usage-preview.html)：按原生界面重绘的两个同时展示位置；选择客户端后侧栏底部联动，设计控件可切换数据状态。所有数值均为设计样例。
- [共同功能清单](../product/mobile-parity.md) F73、[双端 UI 规格](../design/mobile-parity.md) UI02／UI03／UI12、[验收登记](../acceptance/mobile-parity.md) F73。

本轮的完成条件是这些设计可审查，且手机 UI 留有明确确认点；不以文档完成或浏览器预览宣称接入已完成。

## 已核对的现状

1. Codex 官方 App Server 有 `account/rateLimits/read` 与 `account/rateLimits/updated`。返回可以包含多额度桶、窗口、credits、套餐及到达限制的状态；优先读取 `rateLimitsByLimitId`，旧字段只做兼容回退。[官方说明](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)
2. 本机当前账号的一次桌面工具只读查询返回一个 10080 分钟窗口、`secondary: null` 和 credits 余额。用户确认此账号为 Pro，且没有 5 小时限制。该现象只说明当前账号和当前返回；实现不得根据 `planType === "pro"` 隐藏、补齐或推断窗口。
3. 本仓库 `CodexHistoryReader` 与 auth metadata 的方法白名单尚未包含额度查询，Host 没有额度 HTTP 接口，公共协议和手机尚无对应类型。
4. EasyWork 手机当前通过具名 RPC 及明确只读白名单访问原桌面，LAN／Relay 复用领域契约；当前仓库未发现额度读取方法。消息中的 `token-usage` 是单次任务用量，不能充当账户余额或剩余额度。EasyWork 的真实计费接口、单位、账户／组织范围与原桌面提供能力须在实施时核对，当前不虚构接口路径和返回值。
5. EasyWork 通过原桌面的接入路径工作；不为了统一 UI 将其绕接到 Codex Host，也不让 Relay 持有模型／计费凭据。公共领域接口与展示规则统一，来源适配分别实现。

## 边界与兼容策略

- 额度是账户／组织／额度池信息，通过所选机器运行时读取；它不是单个聊天的配额。具名读取固定完整机器目标，不伪造 thread ID。现有线程命令仍保持原有目标约束。
- Codex 的账号信息仅是历史／展示元数据。额度来源改变时撤下旧额度数值并读取新来源，不能因此拒绝连接、历史、草稿、普通读取或命令；其他 Agent、设备与项目权限按原协议执行。
- 一个快照可以同时返回多个余额和多种限制。除非来源明确提供组合语义，不推断“先花 credits 再解除窗口”或“余额大于零即可运行”，也不替代原 Agent 的执行／计费判断。
- 新 HTTP／RPC 能力仅在 provider 实际就绪后声明；旧 Host／旧 EasyWork 维持现有功能，额度页显示不支持。读取失败不导致全局连接失效，不更新正常聊天的命令能力。
- 读取严格有界。建议来源超时 8 秒、页面前台刷新最短间隔 30 秒、用户主动刷新最短间隔 5 秒；同目标请求合并。离页／后台停止轮询；复用已有更新通知，不新建常驻监听或模型任务。最终预算由 U2／U3 实测确定。
- 不新增充值、兑换、消耗重置券、修改套餐或购买动作。额度读取使用现有受信任连接，不引导手机录入模型密钥。

辅助检查将覆盖契约和适配边界；真实 DEV 用本机准确的独立验收 App 和 Wi-Fi 配对 iPhone、Xcode／CoreDevice／XCTest 执行。Android、Windows、其他电脑及 EasyWork 实际网络路径分别验收，不能互借结果。真实任务只核对前后返回及对应原任务，计费延迟和显示精度允许数值暂不变化；不制造耗尽、购买或充值来测边界。A6 继续按现有人类暂停范围处理。
