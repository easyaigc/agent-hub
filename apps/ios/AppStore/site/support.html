Agent Hub 帮助与支持

Agent Hub 用于在 iPhone 上查看和管理您授权的电脑上的 Agent 工作：浏览项目与对话、发送文字及附件、查看任务进度并处理审批。任务在所选电脑上执行。

需要帮助或提出隐私请求，请联系 admin@51easyai.com。服务提供方：合肥博璀人工智能科技有限公司。

界面语言

应用支持简体中文和英文。在设置的“语言”中选择跟随系统、中文或 English，立即生效；不会翻译或重新发送已有消息。

同一局域网自动发现与连接

  1. 在您拥有或获授权的电脑上安装并登录受支持的 Agent 桌面应用，配置对应的 Host 连接服务。
  2. 让 iPhone 和电脑接入同一可信 Wi-Fi 或局域网，并允许 Agent Hub 的“本地网络”权限。访客网络、AP 隔离或防火墙可能阻止设备互相访问。
  3. 在 Agent Hub 顶部点开客户端选择器，再点“添加客户端”，选择 Codex 或 EasyWork，等待“局域网”发现列表。核对电脑名称后点选连接。 已配置自动连接的新版 Host 无需输入 Agent Hub 账号、密码、地址或客户端密钥；其他配置可使用二维码或手动配对。
  4. 核对电脑名称与目标项目后，打开对话或创建新对话。首次发送时阅读 AI 数据共享说明，按需要允许该电脑和模型处理内容，然后返回草稿再次点“发送”。授权本身不会自动发送草稿。

局域网直连不要求注册 Agent Hub 账号。电脑端 Agent 和模型服务需自行配置，其登录、费用及数据规则由相应服务决定。可选的 EasyAI 中继使用单独的登录流程；跨网络访问需要另行配置可信网络。电脑端接入配置需要帮助时，请联系上述客服邮箱。

项目任务管理

Task Hub 工作区需要另外配置局域网主服务，并使用管理员分配的成员账号登录。账号、项目权限、服务数据和删除请求由所选主服务的运营者管理，与直接 Agent 连接分开。

连接后的演示步骤

  1. 打开侧栏，查看所选电脑的项目与对话；点新建对话，选择项目或可用的“无项目”入口。
  2. 发送无副作用的测试内容，例如“仅回复：Agent Hub 连接成功。不要使用工具。”核对 App 内回复与电脑端同一对话。
  3. 切换已授权的客户端，确认项目和对话随电脑切换。执行、审批及其他操作是否可用取决于电脑端运行状态。

没有电脑时查看界面示例

打开侧栏底部个人／设置入口，在“本地体验”中启用“界面示例”。示例中的电脑、项目及对话均为本地合成数据，不向电脑或 AI 服务发送内容；它只用于了解界面，不提供真实模型、电脑执行或完整功能审核环境。

管理 AI 数据共享许可

可在设置中的“AI 数据共享”查看并撤销已允许的电脑和模型。撤销后再次提交需重新同意；已提交给电脑或服务的内容不会因此自动删除，正在执行的任务需另行停止。许可范围以界面披露为准；选择跟随电脑配置表示允许该机器目标当前及之后调整的 AI 配置，请在电脑端核对实际服务商。切换 Agent 或机器运行目标后需要重新确认。

无法连接电脑

请确认电脑已开机、桌面应用已登录、Host 服务正在运行，手机能够访问连接地址，且密钥或配对授权仍有效。局域网连接还需在 iOS 设置中允许“本地网络”。如果只连接到历史读取服务，部分执行功能可能不可用。

任务已发送但结果不确定

先恢复连接并查看原对话或操作回执，必要时在电脑上核对结果。避免重复发送同一项可能已经执行的任务。电脑端运行状态与消息结果是判断是否完成的依据。

通知或语音不可用

通知需要 iOS 通知权限和电脑端推送配置；还请检查系统静音与专注模式。听写需要麦克风及语音识别权限，部分设备或识别方式可能需要网络。可在系统设置中检查相应权限。

提交问题

请在邮件中提供 App 版本、iOS 版本、Agent 类型、问题发生时间、操作步骤和去除敏感内容后的截图。请勿发送账号密码、完整访问密钥、私人聊天或未经授权的文件。您也可以通过该邮箱请求访问、更正或删除我们控制的个人信息。
