# Host 图像代理验收（2026-10-29）

范围为 F74 外部推理 API 的 Images 扩展。原手机 UI、桌面会话 owner、Relay、正式服务配置与 A6 暂停范围保持；不把此前的直连研究结果当作本次产品代理通过。

## 实现

默认关闭的图像模型允许清单、生成 JSON、编辑 JSON／SDK multipart、参数偏好适配、实际输出文件头校验、最终图片 SSE 和独立资源预算已实现。当前图像模型只声明 `gpt-image-2`；`n=1`、Base64 返回、无局部预览。不支持的参数提交前明确拒绝。

图像复用原只读桌面授权和固定具名上游。回执保存原请求及转换摘要；未知结果不重放。补齐错误回执先于响应持久化，以及流在持久化间隙发生错误时的接收保护；同一操作忙碌时仍明确拒绝重复提交。

## 辅助检查与真实结果

新增十二组图像边界／HTTP 集成回归，与既有十三组 Responses 回归组合通过。首次检查中暴露的回执查询竞态、早到 stream error 和忙碌时重复 ID 状态已修复，失败摘录保留在本机私有验收目录。构建、lint、类型检查、本次文件格式及二十五项专项回归通过；连接／打包的五十项辅助检查通过。Agent contract 首次因命令行工具选择导致 xcrun 失败，按命令指定已安装 Xcode 后通过。

## 隔离真实 Host HTTP

- DEV v1：真实生成约 20.6 秒、SDK multipart 编辑＋最终图片 SSE 约 48.3 秒通过，均返回 1672×941 PNG、completed 回执、一次上游提交。蓝底白圆变成绿底白圆的原图已查看；SSE 含连接心跳的完整字节摘要与回执一致。
- 收尾补齐可选 null 参数兼容，以及初始回执尚未写完时的重复 ID 拒绝。DEV v2 对该版本的新操作在约 301 秒时客户端结束，原操作最终为 outcome-unknown。此前 Host 已取得上游 HTTP 200，但没有完整可用结果；底层客户端错误码未记录，原因未唯一确定。原输入未重放，失败与最后回执分别保留。
- 验收器后续使用原生 HTTP 和显式超时，保留后续错误类别／错误码；使用不同的三角形合成内容作为 DEV v3 独立验收，不重放 v2 输入。v3 原生 HTTP 请求在约 154.9 秒时取得 Host 502，原上游已返回 200 并接收约 1.59 MB，但未取得可用完整图片，原回执保留 unknown；没有重放。验收器补充只读 end／close／aborted／错误码观察后，使用不同的横条内容进行 v4 独立验证，v4 当前生产源码／dist 的真实生成约 28.2 秒、multipart 编辑＋最终图片 SSE 约 21.3 秒均通过，各一次上游提交、1672×941 PNG、completed 回执；end／close 均确认 complete=true，SSE 原字节摘要与回执一致。粉底蓝横条改为黄底蓝横条的原图已查看，并由独立图片读取工具核对尺寸。两条旧 unknown 操作仍保留；本次通过不能抹去此前失败。

当前通过绑定生产 Host／Adapter 源码及实际加载 dist 的 SHA-256，另有元数据／PNG 摘要与独立解码核对。这里没有把验收器的后续诊断代码更新写成更早运行的证明。

所有监听均为独立回环 DEV 实例，使用各自私有 Key／账本；完成或失败后关闭并核对 owner 文件移除。没有重启或修改正式 Host 服务，也未将此前研究脚本的直连结果冒充本次代理通过。

## 全局检查的既有阻塞

完整 pnpm check 在格式检查被两个非本任务的用量脚本阻断：scripts/distribute-usage-runtime.mjs、scripts/mobile/usage-easywork-live.mjs。全局双端覆盖检查另被 apps/android/src/main/kotlin/com/agenthub/android/UsageViews.kt 的既有缺失／过期记录阻断。这些文件不作为本任务修复范围，也不将辅助检查和局部通过改称全仓通过。

物理 iPhone、Android 原生、Windows、本轮多图／蒙版／远程引用与完整公共 API 参数等价性均未验收；不能由本机接口通过推定。当前通道未证明原生 2K，尺寸与编码偏好不保证精确生效。

## 模型选择语义补充

2026-10-29 使用独立操作绕过本地允许清单，仅测试同一固定 Codex 生成上游对模型名称的处理。一个编造的模型名仍返回 HTTP 200、完整 PNG（1536×1024），且响应没有实际模型标识；上游提交一次、无重试。因此此前“gpt-image-2 已验证”只表示该兼容配置可以出图，不证明后端严格按 model 路由，也不能据此声明其他模型可用。当前代理继续只开放该兼容配置；程序及正式配置未修改。原反例意图、摘要和产物保留在本机私有调研目录。
