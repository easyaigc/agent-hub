# 原桌面接入按资源授权

状态：已实施，真实验收结果另记。日期：2026-10-24。

原桌面已负责项目、会话及模型执行权限。Host 不再以固定项目根目录约束整台电脑，也不把目录存在性作为建议与内容读取的就绪条件。无新增路径白名单、配置迁移向导或手机权限页面。

- `HOST_AGENT_ROOT` 在桌面模式只保留默认 cwd 兼容语义；已有值无需重写。Windows 启动脚本不再要求该目录存在。托管／共享模式的显式目录策略保持。
- 建议依据准确原 owner、当前原桌面实例、最新完成轮、原生预测来源及私有 Trace 完整性读取；不检查项目文件夹 inode 或是否存在。不改变私有 Trace 的真实路径、祖先、权限、文件身份及完整性校验。
- 桌面下载仅接受当前会话已登记附件的准确文件路径。上传及内联产物登记具体文件；原助手消息的文件引用登记具体只读资源。结构化工具路径的初次登记仍受原会话目录约束，不能用手机任意路径或用户正文制造授权。会话目录只是该来源的一项登记依据，不成为整台电脑的总开关。
- 文件目标重新解析、符号链接改指、会话归属、大小、摘要和实际系统拒绝保持检查。准确资源授权先于无关候选目录检查；某个旧候选目录不可用只撤去它自己的授权依据，不能否决另一有效依据。
- 执行仍使用原 Agent 的有效权限与审批，手机明确选择的模式继续生效。EasyWork 创建项目的上游目录引用和授权协议保持。
- 不新增任意路径读取接口，不改写已有设备凭据、原消息、已提交输入或未知操作回执。

影响共同功能 F16、F17、F26、F27、F31、F32、F35、F59、F62、F69。iOS／Android 沿用相同 Host 及具名操作，未改变端上界面；新功能状态和逐平台验收见双端清单与专项验收。
